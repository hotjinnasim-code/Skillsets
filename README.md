## 덕테이프 포스터

[덕테이프 포스터](skills/ducttape-poster/SKILL.md)는 내용과 디자인 조건을 받아 서로 다른 전체 스타일의 완성 이미지 다섯 장을 만듭니다.

- 스타일의 차이를 우선합니다. 이미지 표현·편집, 색·대비, 타이포그래피의 목소리, 재질·마감과 정서가 만드는 정체성을 현재 내용에 맞게 설계합니다. 좋은 레이아웃·Title/body 순서·정렬은 여러 스타일에서 공유할 수 있으며 다섯 구도를 모두 다르게 만들 의무는 없습니다. 단순 필터·폰트 교체만으로 스타일 차이를 대신하지 않습니다.
- 중앙이 다섯 방향을 함께 설계하고 독립 제작자 다섯 명이 한 장씩 맡습니다. 가용 한도 안에서 동시에 실행하며 남은 역할도 끝냅니다. 사용자 수량·좁은 지정 스타일·비율·구도 보존 조건을 우선합니다.
- 본문이 읽힐 크기·줄 폭·행간과 실제 문장의 면적을 먼저 확보합니다. 제목·보조 언어·설명·행사·참여 문구의 역할을 실제 크기·굵기·대비로 구별하고, 문단 끝에서 다음 안내의 시작으로 이어질 정렬·인접·이미지 방향을 설계합니다. 글을 빈 모서리에 흩뿌리지 않으며 거친 이미지에도 본문은 정밀하게 조판합니다. 한글·라틴·숫자의 형태와 무게, 의미 있는 단어 간격과 원문 기호를 함께 선택합니다.
- 레퍼런스는 발상·스타일·이미지·색·레이아웃·정보·글자·마감을 배우는 재사용 가능한 아이디어 라이브러리입니다. [22개의 구성 아이디어](skills/ducttape-poster/references/design-grammar.md)를 현재 내용에 맞춰 변형하며 고정 다섯 스타일 메뉴로 쓰지 않습니다. 매 요청·제작자마다 새 검색이나 원본 재열람을 의무화하지 않습니다.
- 기본 출력에서 단색·유사 단색·분할 색 바탕의 큰 고딕 제목과 안내 블록에 이미지가 부가된 템플릿을 제외합니다. 작은 사진·질감·폰트 교체나 빈 실내 면으로 같은 구성을 꾸미지 않습니다. 클레이 한글·보색·장난감 덩어리와 큰 오브젝트·큰 제목·작은 하단 안내의 반복도 기본값으로 삼지 않습니다. 고딕·여백·강한 표현 자체를 금지하지 않으며 명시적 사용자 구성·표현은 해당 범위에서 우선합니다.
- 내장 이미지 도구로 독립된 평면 포스터를 실제 제작합니다. 전체 카피를 보존하고 사용자 이미지는 실제로 본 뒤 수정·구도·스타일·대상 재현의 역할에 맞춰 참조합니다. 한 장의 후속 수정은 그 대상에만 적용합니다.
- 실제 문구를 eyebrow·Title·Subtitle·body copy·footer의 기능으로 정리합니다. Title은 즉시 제목으로 인지되는 주된 타이포그래피 앵커로 만들고 보조 문구·본문·안내와 강약을 구별합니다. 한 포스터 안의 서체 골격·폭·획 대비·무게와 한글·라틴·숫자의 기준선을 조화시키며, Title만 있으면 제목으로 완결하고, Title+body만 있으면 두 역할의 위계와 이어 읽기를 설계합니다. 없는 eyebrow·Subtitle·Footer·일정·URL이나 고정 폰트·크기 배율을 추가하지 않습니다.
- 설명 문단과 실용 안내가 함께 있는 복잡한 카피는 사용 가능한 기존 글꼴·렌더러로 실제 문구와 내용의 실질적인 이미지 형태를 먼저 스케치합니다. 시점·크기·빛·크롭·접촉과 본문의 면적·줄 묶음·읽는 관계를 함께 구체화합니다. 단순 문구·무문자·사용 가능한 환경이 없는 요청은 긍정적인 네이티브 명세로 바로 제작하며 원작 재열람·새 승인·설치를 의무화하지 않습니다. 스케치는 최종 스타일이나 사용자 구도 보존 조건이 아니며 최종 포스터는 내장 이미지 도구로 만듭니다.
- 최초 생성의 긍정적인 제작 명세에 작업의 중심을 둡니다. 일반 사용에서는 문구·조건·사용 크기 판독·명백한 결함을 확인하며 별도의 점수표나 외부 평가자를 추가하지 않습니다. 필요한 보정은 이미지당 최대 두 번이며 실제 전후 장단점을 보고 선택합니다.
- 개선 실험은 한 요청의 다섯 장을 완전히 평가하고 공통 원인을 지침에 반영한 뒤 다음 요청으로 진행합니다. 독립 평가자 세 명이 내용·계층·타이포그래피·공간·이미지와 재질·정서·AI 슬롭을 모두 판단하고 전체 다양성도 따로 봅니다. 불리한 점수와 판정 불가는 보존합니다.

가능한 최대 해상도를 요청하고 반환 크기를 확인합니다. 프롬프트만으로 4K나 실제 폰트 파일 적용을 보장하지 않습니다. AI 슬롭은 범용 구성·임의 장식·붙인 글자·가짜 세부·합성 결함에 관한 디자인 판단이며 제작 주체 판별이 아닙니다.

## 설치와 사용

`skills/ducttape-poster` 폴더를 `~/.codex/skills/ducttape-poster`로 복사합니다. Codex에서 `$ducttape-poster` 또는 `덕테이프 포스터`를 호출하고 넣을 문구와 목적·매체·디자인 조건을 적습니다. 제목만 있거나 글자 없는 요청도 처리하며 임의 행사 정보나 본문을 만들지 않습니다.
