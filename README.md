# Skillsets

Codex에서 사용하는 스킬 모음입니다.

## 덕테이프 포스터

`skills/ducttape-poster`는 내용과 디자인 조건을 받아 완성된 포스터 이미지를 만듭니다.

- 내용에 맞춰 서로 다른 다섯 스타일을 자동으로 결정합니다.
- 각 방향의 시각적 발상, 이미지와 글자의 공간 관계, 정보 계층을 함께 설계합니다.
- 스타일을 맡기면 내용·글자·제작 원리에서 후보를 비교하고 범용 효과 패키지의 기본 우선순위를 낮춥니다. 명시한 네온·3D 등은 그대로 존중합니다.
- 스타일마다 독립 이미지 한 장씩, 기본 다섯 장을 생성합니다.
- 중앙에서 카피와 방향을 정하고 제작자 다섯 명이 한 장씩 맡습니다. 가용 한도 안에서 병렬 실행하며 한도가 낮으면 남은 역할을 나눠 실행합니다.
- 사용자가 지정한 문구, 스타일, 디자인 요소, 비율과 수량을 우선합니다.
- Codex 내장 이미지 도구를 사용하며, 프롬프트만 전달하는 모드는 제공하지 않습니다.
- 고정된 스타일 목록이나 팔레트 없이 디자인을 결정하고 사용자 참조 자료가 있으면 해당 역할에 맞게 반영합니다.
- 실제 결과를 축소·사용 크기·원본 크기에서 검수하고, 한글 문구·간격·정렬·재질과 전체 시안의 차이를 확인합니다.
- 긴 카피와 한영 혼용 문자는 자형의 비례를 지키고, 면적·크기·줄 묶음과 실제 글자·대상 경계를 함께 조정합니다.
- 사진 표면은 형태·빛·초점에 맞게 다루며, 국소 보정 뒤에는 바뀐 영역 밖의 윤곽·표면도 전후 비교합니다.
- AI 슬롭 방지를 별도로 검수하고, 고급 완성도나 자료 조사를 요청하면 실제 포스터·타이포그래피 및 공식 디자인 자료의 원리를 참고합니다.
- 문구와 필수 조건 위반을 먼저 고치고, 이미지당 최대 두 번의 보정 안에서 구도와 마감을 개선합니다.
- 보정 전후를 비교해 가장 적합한 결과를 선택하며, 최신 이미지가 더 낫다고 가정하지 않습니다.
- 가장 약한 시안까지 같은 기준으로 검수하며, 표면 보정이 주제 단서와 가독성을 약화시키지 않는지 확인합니다.
- 가능한 최대 해상도를 요청하고 실제 결과의 픽셀 크기를 확인합니다. 내장 도구가 크기 설정을 제공하지 않으면 4K 출력을 보장할 수 없습니다.

## 설치와 사용

`skills/ducttape-poster` 폴더를 로컬 Codex의 스킬 디렉터리에 복사합니다. 기본 경로는 `~/.codex/skills/ducttape-poster`입니다.

Codex에서 `$ducttape-poster` 또는 `덕테이프 포스터`를 호출하고, 포스터에 넣을 내용과 원하는 디자인 조건을 적습니다. 후속 수정은 지정한 이미지에 적용합니다.

평가용 가상 요청은 [평가 사례](evals/ducttape-poster/cases.yaml)에 있습니다. 실제 생성·독립 평가·보정의 개선과 퇴행은 [평가 보고서](evals/ducttape-poster/report.md)와 비교 이미지에 기록했습니다. 스킬의 실제 산출물을 비교하는 방법은 `skills/ducttape-poster/references/evaluation-loop.md`에 있으며, 일반 제작에 다중 에이전트 평가를 필수로 추가하지 않습니다.

제목만 있는 기본 다섯 장, 긴 모집 안내, 제품 사진, 명시적인 3D·크롬·네온을 추가로 실행한 결과와 다섯 제작자 구조의 실제 검증은 [추가 평가 보고서](evals/ducttape-poster/round3/report.md)에 기록합니다. 제작자 수와 실제 동시 실행 한도, 버전별 결과와 보정 후 선택, 평가자 간 차이를 구별합니다.

내용이 글자·이미지·정보 묶음을 결정하도록 방향 비교를 강화한 결과는 [내용별 구성 평가](evals/ducttape-poster/round4/report.md)에 기록합니다. 여섯 가상 요청의 후보별 원본·보정·독립 리뷰와 선택 14장의 파일 해시를 연결했습니다. 새 D 3장의 개별 핵심 항목 통과와 전체 품질 기준 미통과를 구별하며, 미해결 항목도 보존합니다.

재질·자형·접점 지침을 새 사례와 독립 평가자로 다시 검사한 결과는 [전이 평가 보고서](evals/ducttape-poster/round5/report.md)에 있습니다. 선택 14장과 별도 글자·여백 제약 사례의 원본, 세 크기의 실제 보기, 모든 원점수·불확실성과 호출 경계를 보존합니다. 여러 버전의 선택 근거와 최신 버전의 새 사례 검증 범위를 구별합니다.

메인 스킬을 고정하고 네 새 요청의 다섯 시안씩을 실행한 [추가 20장 검증](evals/ducttape-poster/round6/report.md)과 [갤러리](evals/ducttape-poster/round6/gallery.html)도 보존합니다. 최종 개별 기준은 통과 1장·품질 미통과 14장·판정 불가 5장이며, 완전한 세트 통과는 없습니다. [핵심 발견](evals/ducttape-poster/round6/findings.md)은 AI 슬롭·다양성·필수 조건의 잔여 문제와 공백 전사 표기에 따른 판정 불가를 구분합니다. 47개 생성 원본, 최초·최종 24개 새 평가 세션, 모든 일곱 원점수와 제작·실행 한도의 예외를 연결하며 향후 모든 요청의 품질을 보장하지 않습니다.
