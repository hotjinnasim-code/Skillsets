# 시각 자료 조사

하이엔드 완성도·AI 슬롭 방지·적극적인 자료 활용을 요청받았거나 주제의 시각 언어가 불분명할 때 읽는다. 아래는 탐색의 출발점이며 고정 레퍼런스 세트가 아니다. 일반적인 요청을 조사만 하다가 끝내지 않는다.

## 조사에서 제작으로 연결하기

현재 내용·카피 밀도·매체·표현 제약과 관련된 실제 작품을 소수 확인한다. 서로 다른 제작 방식이나 타이포그래피 접근도 비교한다. 가능하면 디자이너·디자인 스튜디오·미술관의 원문과 실제 이미지를 보고, 검색 설명이나 재게시한 분위기 모음만으로 평가하지 않는다.

각 자료에서 **구성의 작동 원리, 글자와 이미지의 관계, 재질·제작의 일관성, 이 요청에 적용할 이유**를 짧게 내부 기록한다. 원문이 직접 설명하는 내용과 내가 작품을 보고 추론한 내용을 구별한다. 주제와 맞지 않는 취향은 가져오지 않는다.

자료 조사를 길게 프롬프트에 붙이거나 작품 이름만 나열하지 않는다. 확인한 원리를 현재 카피와 주제의 구체적인 크기·간격·형태·공간 관계로 바꾼다. 레퍼런스의 작품 정보·가짜 제작 표식·유명 로고를 장식으로 가져오지 않는다. 사용자가 특정 구도를 유지하라고 한 경우에는 그 요청을 우선한다.

연구용 이미지와 사용자가 준 필수 이미지, 수정 대상을 구분한다. 실제 이미지 파일을 도구에 입력하면 참조 역할과 유지·교체할 부분을 명시한다. 단지 URL을 읽었다고 생성 도구가 이미지를 보았다고 말하지 않는다. 자료 이미지 자체를 스킬의 출력용 자산으로 묶지 않는다.

## 확인한 자료와 적용 범위

2026-10-07에 확인한 1차 자료다. 웹·GitHub 내용은 바뀔 수 있다. 특정 스타일을 기본값으로 만드는 대신 필요에 맞는 원리를 확인한다.

| --- | --- | --- |

표의 오른쪽 열은 이 스킬을 위한 적용 판단이며 원문이 보장하는 평가 척도가 아니다. 원작 자료는 조사에 활용하며 자신의 생성 이미지를 원작 디자이너의 작업으로 표시하지 않는다.

## 제작 방식과 다양한 요청의 추가 자료

같은 날 추가로 확인했다. 단순히 크롬·네온을 빼고 아이보리 종이로 바꾸는 해법 대신 실제 사진·그림·밀도·글자 구성의 원리를 비교한다. 오른쪽 열은 관찰한 작품에서 이 스킬로 옮긴 판단이다.

| 자료 | 원문에서 확인한 내용 | 포스터에 적용할 판단 |
| --- | --- | --- |
| [Pentagram — The Public Theater](https://www.pentagram.com/work/the-public-theater) | 공연자의 탭과 주변 글자를 도시의 소음에 연결하고 공연별 캠페인을 달리함 | 구체적인 대상과 행동도 구성의 중심이 될 수 있음; 복잡한 은유나 같은 장식 패키지가 필수는 아님 |
| [Studio Dumbar — Amsterdam Sinfonietta](https://studiodumbar.com/work/amsterdam-sinfonietta) | 개별 포스터가 공연의 음악 주제에 그래픽으로 반응하며 시즌마다 새 접근을 적용 | 반복·밀도·방향·큰 제목의 규칙으로 에너지를 설계하고 안내와의 역할을 구분 |
| [Sulki & Min — Professionalism](https://www.sulki-min.com/wp/professionalism/) | 참여자들을 레슬러로 표현한 전시 포스터와 인쇄·서체 정보를 설명 | 조밀한 한글·영문도 묶음과 정렬의 일관성으로 제어; 미니멀리즘을 품질의 유일한 해법으로 보지 않음 |
| [Ida Henrich — DCA film posters](https://idahenrich.com/portfolio-item/art-house-film-poster-dundee-contemporary-arts/) | Tár의 통제라는 주제를 메트로놈과 손의 움직임으로 표현 | 그림의 실루엣·행동·선·선택적 세부로 주제를 보이게 함; '따뜻한 손그림' 형용사만으로 지시하지 않음 |
| [Version Industries — posters](https://versionindustries.com/work/tag/poster) | Curfew의 소품 선택·장면 설치·조명·촬영, Desire Lines의 물리적 표면 제작을 설명 | 사진의 시점·빛·접촉·재질 반응이 같은 장면의 규칙을 따르는지 검수; 원작 소품·구도를 기본값으로 가져오지 않음 |

특정 효과의 AI 사용 빈도를 위 자료로 입증했다고 말하지 않는다. Anthropic의 현재 frontend-design은 따뜻한 크림·세리프 같은 조합도 반복적인 기본안의 예로 다룬다. 그 조합이나 네온 등의 유무 대신 현재 요청에서 필요한 역할과 실제 완성도를 판단한다.

## 최신 자료의 날짜 확인

2026-10-07에 공식 GitHub API로 각 파일 경로의 마지막 변경 커밋을 확인하고 `main`과 해당 커밋의 파일 바이트가 같은지 대조했다. frontend-design은 [2026-09-02 커밋](https://github.com/anthropics/claude-code/commit/dbdd79cebfae5891f5b0fab6f7773ea520d289a7), canvas-design은 [2025-12-01 커밋](https://github.com/anthropics/skills/commit/ef740771ac901e03fbca3ce4e1c453a96010f30a)이었다. 후자는 경로 이동 커밋이며 새로운 디자인 원칙의 발표라고 해석하지 않는다. 이는 레포 전체의 최신 커밋 날짜와도 다르다.

다음 최근 자료의 실제 이미지도 확인했다. 작품 연도·페이지 게시일·확인일을 구별하며, 최신이라는 이유만으로 원칙을 채택하지 않는다.

위 적용 판단은 작품 관찰에 따른 추론이다. 원작의 반복 카피·로고·색상·레이아웃을 기본 템플릿으로 가져오지 않는다.
