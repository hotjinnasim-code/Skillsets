# 축적한 디자인 아이디어를 재사용

레퍼런스는 매력적인 포스터의 발상·이미지 표현·크롭·편집·색·공간·글자·정보·마감을 배우는 **아이디어 라이브러리**다. 매 제작 요청마다 새 검색·원본 재열람·제작자별 출처 대응표를 요구하지 않는다. 사용자가 지정한 참조·보존 자산의 실제 열람과 정확한 도구 전달은 별도 필수 조건이다.

중앙은 현재 내용·카피·언어·매체에 맞는 스타일을 설계하며, [구성 문법](design-grammar.md)의 22개 관계 아이디어는 필요할 때 선택적으로 참고한다. 이미지 표현·편집·색·대비·글자·재질·정서를 폭넓게 발상에 활용하고 레이아웃 차이를 우선 조건으로 삼지 않는다. 원본 한 작품을 한 결과의 답안으로 대응시키거나 원작의 사진·인물·로고·카피·배열을 이식하지 않는다. 반복 장면·사진 편집·도해·삽화·공유 경계 등은 열린 발상의 출발점이며 영구적인 다섯 가족이나 스타일 순위가 아니다.

## 표현 결정을 꺼내 쓰는 짧은 예

매체 이름 뒤에 현재 내용에서 실제 인상을 결정하는 거리·초점·형태·색·글자·마감의 선택과 이유를 적는다. 모든 차원을 채우는 서식은 아니다. 다음은 기존 실제 관찰에서 압축한 선택적 아이디어이며, 작품 하나를 결과 하나에 대응시키는 배정표·고정 스타일 메뉴가 아니다. 같은 좋은 읽기 정렬에서도 표현의 결합은 달라질 수 있다.

- **사진의 긴장과 글자의 명료함:** BP2025-009·072의 명암·선택 색·초점 차이에서 사진의 거리와 또렷함, 작은 색이 맡는 연결을 배운다. 현재 내용에 맞는 장면과 Title의 목소리를 선택하며 본문까지 흐리게 만들거나 원작 얼굴·베일·손글씨를 가져오지 않는다.
- **서로 다른 묘사가 만나는 이미지:** BP2024-086의 사진·그림·편집 리듬에서 각 표현이 맡을 식별·해석·스케일을 정한다. 종이 조각을 쌓는 대신 무엇이 만나 어떤 의미를 만드는지 설계하며 원작 정물·격자를 복제하지 않는다.
- **평면의 비례와 동작:** east-FNT-02·04의 날카로운 획·열림, 곡선의 움직임과 이미지 경계를 참고해 현재 대상의 특징에서 표현 어휘를 만든다. 색의 무게와 Title의 리듬을 조화시키고 본문은 정밀하게 읽게 한다. 원작 로고·삼원색 조합·인물·제목 모양을 이식하지 않는다.
- **면과 세부의 다른 밀도:** east-SM-03의 큰 색면·가는 선·중첩·미세한 표면 차이에서 광택이나 원근 없이 깊이를 만드는 선택을 배운다. 현재 내용의 큰 형태와 작은 관찰을 연결하며 원호·회전 안내나 극도로 가는 활자를 긴 한글 본문의 답으로 삼지 않는다.

이는 [기존 관찰 색인](reference-catalog.json)의 아이디어를 새 내용으로 옮기는 해석이다. 원작의 모든 작은 글자·폰트 파일·인쇄 공정을 확인했다는 뜻이 아니며 새 검색·원본 재열람·source ID 기입을 제작 의무로 추가하지 않는다.

## 조사 기록과 범위

이번 개선 연구는 공식 [100 Beste Plakate 아카이브](https://100-beste-plakate.de/plakate/)의 2024·2025년 두 해에서 **작품당 한 이미지씩 200개**를 실제 구도 수준에서 관찰했고, 본문·편집이 중요한 8개는 로컬 원본을 추가 열람했다. 스튜디오 연구는 별도 실제 원본 37개를 보고 시리즈 중복·지원 매체·미확인을 구별해 20개의 유효 포스터 작품/시리즈 그룹으로 보수적으로 집계했다. 그중 19개는 전체 또는 부분 아이디어이며 1개는 제외 구성의 반례다. 200개와 20개는 서로 다른 조사 집계이며 출처의 유명세·수상을 품질 증거로 쓰지 않는다.

사진 편집·인물/사물 크롭·반복 동작·일러스트·회화·몽타주·기하 구조·도해·재질·다언어·장문 프로그램의 다양한 관계를 축적했다. 일부 유명 작품도 기본 정보판·장난감 패키지와 겹치거나 본문이 지나치게 작으면 전체 스타일 추천에서 제외하고 유용한 부분만 취한다. ‘whole-positive’는 참고할 전체 발상이 있다는 연구 분류이며 원작 모든 세부가 스킬 품질 기준을 통과했다는 뜻이 아니다. 작은 글자 판독 한계와 프로젝트 대응이 미확인인 이미지도 기록에 남긴다.

세부 출처·식별자·실제 관찰·범위는 선택적으로 [참조 색인](reference-catalog.json)에서 찾는다. 이 큰 색인을 기본 제작 때 모두 읽거나 원본 200개를 다시 열지 않는다. 다운로드 수·원문의 저자 크레딧 표기 수·실제 본 작품 수·유효 포스터 수를 구별한다. 레퍼런스 이미지는 로컬 연구용으로 보존했고 재사용 가능한 고객 자산으로 인증하지 않는다.

## 추가로 자료를 볼 때

사용자가 특정 작품을 지정했을 때, 현재 설계에 필요한 새로운 표현이 있을 때, 라이브러리를 보강할 때만 관련 공식 자료를 본다. 실제 전체 이미지를 확인하고 유용한 결정을 자기 말로 간단히 남긴다. URL·검색 요약·파일명·수상 사실만으로 색·배치·마감을 봤다고 하지 않는다. 같은 시리즈의 색·목업·적용 매체를 서로 다른 작품으로 부풀리지 않는다.

한국·다국어 자료로 [studio fnt](https://studiofnt.com/), [일상의실천](https://everyday-practice.com/), [슬기와 민](https://www.sulki-min.com/wp/), [Ordinary People](https://ordinarypeople.info/)를, 전체 이미지 표현의 추가 탐색으로 [Studio Feixen](https://www.studiofeixen.ch/), [Studio Dumbar](https://studiodumbar.com/), [Hey](https://heystudio.es/), [HORT](https://hort.org.uk/), [PORTO ROCHA](https://www.portorocha.com/), [Pentagram](https://www.pentagram.com/work/the-public-theater/story)을 활용할 수 있다. 한 프로젝트의 스타일을 스킬의 고정 기본값으로 만들지 않는다. 화면이 로고·책·공간 사진이면 포스터 사례로 세지 않고 매체의 역할을 구별한다.

대중적인 행사 식별·방문 판단·기능별 정보 묶음은 [Canva 행사 포스터](https://www.canva.com/posters/templates/event/)도 보조 자료로 참고한다. 친숙하고 읽히는 관계를 배우며 상위 템플릿의 제목·날짜·이미지 틀을 기본 판형으로 가져오지 않는다. 이번에 실제 본 [Fall Festival](https://www.canva.com/templates/EAFvw09FduA-brown-illustrated-fall-festival-poster/)은 기간·장소 묶음의 부분 참고 자료이며, 큰 중앙 고딕 글자와 주변 잎 장식을 전체 고급 스타일 예시로 채택하지 않는다.

[Pretendard](https://github.com/orioncactus/pretendard), [SUIT](https://github.com/sun-typeface/SUIT), [Adobe 본명조](https://github.com/adobe-fonts/source-han-serif)는 실제 한글·라틴·숫자의 안정된 글자 형태를 보는 보조 자료다. 글꼴 이름만으로 래스터 이미지에 폰트 파일이 적용됐다고 주장하지 않는다. GitHub의 디자인 스킬·문서는 조사·지침 구조의 보조 근거로 쓰며 다른 도구의 절차·고정 스타일·비율을 그대로 이식하지 않는다.

## 결과로 확인

작품 수나 닮은 정도는 생성 품질의 증거가 아니다. 현재 카피의 판독·조건·본문 흐름·글자와 이미지 마감, 다섯 결과의 실제 스타일 정체성을 본다. 좋은 읽기 순서와 정렬을 공유하는 것만으로 스타일 차이가 없다고 판단하지 않는다. 생성 전에는 [제작 명세](production-brief.md)의 긍정적인 구성을 해결한다. 일반 제작에 새로운 출처 승인이나 외부 평가자를 추가하지 않는다. 스킬 개선은 실제 한 요청의 다섯 최초 결과를 함께 평가한 뒤 일반적인 설계 원인을 개선한다.
