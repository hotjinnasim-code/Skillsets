# 다섯 제작자 역할로 만드는 독립된 포스터

신규 제작에서는 중앙 조정자가 전체 방향을 함께 설계하고 다섯 제작자 에이전트가 각각 한 장을 맡는다. 사용자 지정 수량이면 역할 수를 맞춘다. 가용 동시 실행 한도 안에서 실행하고 대기 중인 역할까지 끝낸다. 한 장의 후속 수정과 일반 제작에 외부 평가자를 자동으로 추가하지 않는다.

## 중앙에서 먼저 설계

원문·전체 카피·조건과 사용자 자료를 확정한다. 현재 내용과 축적한 아이디어로 각 방향의 스타일 정체성을 설계한다. 이미지 표현·편집, 색·대비, 글자의 목소리, 재질·마감과 정서가 어떤 전체 인상을 만드는지 긍정적인 명세로 전달하고 제작자는 실제 카피에 맞는 좋은 읽기 구도를 자율적으로 선택한다. 잘 읽히는 Title·body 순서와 정렬은 여러 스타일에서 공유할 수 있다. 매 요청의 새 조사나 제작자별 원본 재열람을 기본 단계로 넣지 않는다. 열린 요청에 유명 스타일 하나를 임의로 공유하지 않으며 사용자 지정의 좁은 스타일·브랜드 표현은 공통 조건으로 전달한다. [아트디렉션](art-direction.md)의 실제 스타일·내용 비교를 참고한다.

중앙은 [기본 스타일 제외의 동일한 정의와 적용 여부](art-direction.md#기본-스타일-제외)를 배정 전에 확인한다. 제외가 적용되는 방향에 그 구성이 남으면 작은 그림·질감·하단 이미지 띠나 글꼴 교체를 보탠 경우도 배정하지 않는다. 굵은 고딕 제목·날짜·안내 패키지만으로 전체 인상을 대신하지 않고, 각 방향의 이미지 표현·공간·글자 관계가 전체 인상을 만드는지 확인한다. 현재 적용되는 제외 또는 해당 이미지의 명시적 사용자 해제를 실제 제작 명세와 검수 조건에도 전달한다. 고딕 제목·안내 사용 자체와 제외된 전체 구성을 구별하고 필수 판독을 유지한다.

각 방향에는 **현재 내용에 맞는 스타일 정체성 → 구체적인 이미지 표현·편집·색·서체·마감·정서 → 실제 문구의 역할과 명확한 Title·보조 위계 → 존재하는 본문과 유용한 다음 정보로 이어지는 읽기 관계**를 짧게 적는다. 실제 있는 eyebrow·Title·Subtitle·body copy·footer의 기능을 선택하고 없는 역할이나 새 카피를 추가하지 않는다. 일반 제목이 주어지면 즉시 Title로 인지되는 주된 타이포그래피 앵커로 두며, 크기·무게·대비·여백으로 보조 역할과 구별한다. 다양성을 위해 제목을 작은 표식이나 먼 독립 구역으로 낮추거나 보조 영어·날짜·일반 초대·본문을 역할 근거 없이 경쟁하는 헤드라인으로 키우지 않는다. 사용자 지정 역할·배치·순서와 무문자·제목만의 요청을 우선한다. 첫 시선이 항상 제목이거나 제목이 같은 위치·픽셀·배율이어야 하는 것은 아니다. 명확한 제목 위계와 존재하는 본문·안내의 판독을 유지하면서 각 스타일의 전체 인상을 구현한다. 같은 좋은 읽기 구도는 공유할 수 있고, 다섯 레이아웃·첫 카피 역할·정보 순서·팔레트·서체 수량을 서로 다르게 만들 의무는 없다. 제작자에게는 자기 방향의 긍정적인 스타일 명세와 그 안에서 읽기를 해결할 여지를 준다. 현재 내용의 핵심, 장면·행동·시점·크롭과 카피의 상대적 비중을 구체화한다. 중앙 계획은 실행을 위한 설계이며 추가 사용자 조건이 아니다. 좌표·크기·줄 수·특징 수는 사용자 지시나 사용자 자산의 보존 요구에 근거한 경우에만 고정 조건으로 삼는다. 실제 결과가 계획과 달라도 사용자 조건·필요한 관계·다른 방향과의 실질적 구분을 충족하면 제작자가 중앙 승인 없이 그대로 채택할 수 있다. 실제 실패가 있으면 같은 조건 안에서 관계를 재설계하고 스킬의 보정·선택 기준을 적용한다. 계획에서 달라진 관계와 이유는 결정 뒤 중앙에 알린다.

제작자에게는 자기 방향에 필요한 구체적인 발상·표현·본문 흐름을 전달한다. 아이디어의 출처 이미지나 작품 해설을 항상 함께 열도록 요구하지 않는다. 다른 제작자의 전체 계획·이미지는 공유하지 않는다. 사용자가 지정한 레퍼런스·보존 자산은 실제 경로와 역할을 빠짐없이 전달하고 열람한다. 조사용 이미지를 사용자 자산이나 구도 보존 조건으로 바꾸지 않는다.

중앙은 자기 방향의 스타일 정체성을 짧고 구체적으로 전달하며 다른 제작자의 전체 계획·프롬프트·이미지는 전달하지 않는다. 실제 해당 카피가 있을 때 첫 역할과 보조 문구 사이의 크기·굵기·대비, 문단 끝에서 다음 안내의 시작을 찾는 단서와 이미지의 크롭·열림을 배정 명세에 담는다. 실용 안내의 첫 줄부터 마지막 줄까지 실제 문장 면적을 잡고 그 시작·끝을 비문자 이미지가 있을 때의 경계·주요 정렬축·다음 묶음의 시작과 함께 선택한다. 구역을 전환할 때도 각각 읽히는 섬이나 앞 구역을 재검색하는 경로가 되지 않게 실제 인접·경계·방향·강약으로 연결한다. 표시 크기에서 읽힐 본문 몸체·면적·서체 형태·줄 폭·간격과 안내의 의미 있는 단어 간격·구별되는 기호 형태도 선택한다. 한 포스터 안에서 Title·보조 문구·본문·footer의 서체 골격·폭·획 대비·무게·기준선과 한글·라틴·숫자가 어울리는 체계를 명세하고 제목 효과를 작은 안내까지 전염시키지 않는다. footer도 실제 사용 크기에서 읽히게 하며 모든 실용 안내를 작은 하단으로 몰지 않는다. 무문자 요청은 이미지·공간의 진입점과 연속 관계로 설계하고 짧은 제목만 있으면 그 제목으로 완결한다. 사용자 지정 스타일·배치·순서를 우선하며 한 열·패널·단일 진입점·공통 정보 순서를 추가하지 않는다. 장면의 질감이나 원근 효과를 본문 글자에 자동으로 적용하지 않는다. 제작자는 실제 전체 카피에 맞춰 이를 구체화하며 모든 역할을 통일할 정보 패널·폰트·격자를 임의의 새 조건으로 추가하지 않는다.

복잡한 설명 문단과 실용 안내가 함께 있는 요청에서는 사용 가능한 글꼴·렌더러로 중앙 또는 해당 제작자가 [구성 스케치](layout-guide.md)를 최초 호출 전에 작성한다. 현재 내용에서 선택한 시점·연결·크롭과 실제 카피의 면적·큰 형태를 함께 그린다. 중앙이 작성했다면 자기 방향의 스케치만 전달하고, 제작자가 작성한다면 배정된 구분과 전체 카피로 구체화한다. 스케치는 자기 방향의 실제 이미지·글자 관계를 설계하는 수단이며 다른 스타일과 좌표·읽기 순서를 다르게 만드는 의무가 아니다. 실용 안내가 없는 Title+body만으로 이 복잡한 안내 스케치 절차를 의무화하지 않는다. 새 승인·추가 평가자 없이 진행하며 환경이 없으면 긍정적인 제작 명세를 사용한다.

각 제작자에게 원문 전체, 확정된 전체 카피와 조건·비율, 자신이 맡은 한 방향, 관련 스킬 지침, 필요한 실제 사용자 자산과 역할, 자기 방향의 구체적인 디자인 결정을 전달한다. "배정된 방향 한 장만 제작하며 전체 수량은 중앙이 관리한다"고 명시한다. 제작자는 다른 제작자를 재귀적으로 추가하지 않는다.

다섯 제작자가 동시에 지원되면 모두 독립 실행한다. 한도가 더 낮으면 완료된 자리에 나머지 역할을 배정한다. 별도 채팅·작업이나 다른 실행 수단으로 한도를 우회하지 않는다. 논리적 다섯 역할과 실제 최대 동시 실행 수를 구별한다. 협업 도구가 없으면 같은 전체 설계로 직접 제작하고 실행하지 않은 에이전트를 주장하지 않는다.

## 제작자 한 명의 범위

[최초 생성 명세](production-brief.md)를 따라 자기 방향의 실제 표현·편집·구도·글자 관계를 먼저 해결한다. 긍정적인 제작 명세가 중심이며 금지 목록·평가표로 설계를 대신하지 않는다. 일반 제작은 문구·조건·사용 크기 판독과 명백한 결함을 확인하고 필요할 때만 보정한다. 개선 실험의 계측·원점수 기록은 별도 평가 절차다.

사용자 조건과 배정된 전체 표현 체계, 다른 방향과의 실질적 구분을 유지하면서 실제 카피와 이미지를 하나의 포스터로 구체화한다. 다른 제작자의 생성 이미지·프롬프트를 읽거나 신규 참조로 쓰지 않는다. 필요한 공통 사용자 자료는 빠짐없이 받고 수정·구도·스타일·실제 대상 재현의 역할을 구별한다.

전체 요청은 제작자가 이해하고 검수할 맥락이다. 이미지 도구에는 인쇄 카피 한 벌과 필요한 조건, 선택한 구체적인 이미지·글자·공간 관계, 출력 조건만 명확히 담는다. 원문·카피·조건을 여러 형식으로 반복하거나 평가표·계획 JSON을 붙이지 않는다. 중요한 대상·행동·참조 조건을 잃으면 안 된다. 수정에는 바꿀 부분과 유지할 관계를 전달하고 매번 원문 전체로 결과를 검수한다.

내장 이미지 도구로 단일 평면 포스터 한 장을 실제 생성한다. 독립 출력 경로를 쓰고 원본을 보존한다. 축소·사용 크기·원본에서 전체 문구·조건·한글·구성·재질·AI 슬롭을 확인한다. 재생성을 포함한 자동 보정은 이미지당 최대 두 번이다. 직접 본 전후 결과에서 가장 적합한 최종본을 선택한다.

자기 검수에는 실제 이미지의 첫·다음 앵커와 필요한 카피 전체를 찾은 경로, 해당되는 경우 대응하는 대상 사이의 핵심 특징 비교를 짧게 남긴다. 항목별 판독이나 “같은 모티프”라는 설명으로 관계 검수를 대신하지 않는다. 보정의 국소 마감이 개선돼도 남은 관계 실패를 중앙에 전달한다.

기본 스타일 제외가 적용되면 축소·사용 보기에서 이미지·장면·편집이 실제 전체 구성을 조직하는 관계와 제목·안내 판형에 부가물을 붙인 관계가 남는지도 이 기록에 짧게 남긴다. 명시적 이미지 제외 시 글자·공간의 관계를 확인한다. 이미지의 존재·면적·재료명만으로 해소를 인정하지 않으며 읽히는 정보 묶음이나 단색 여백 자체를 위반 근거로 삼지 않는다.

중앙에 모든 시도 원본과 적합한 선택 최종본의 실제 경로 또는 최종 선택 없음(NONE), 반환 픽셀 크기, 모든 호출·보정 횟수, 문구·조건 확인과 잔여 문제를 돌려준다. 적합한 선택본은 중앙이 실제 파일을 열 수 있는 경로와 함께, 도구가 반환한 이미지 표시·원본 다운로드 참조가 있으면 그것도 전달한다. 표시용 축소본과 선택한 생성·보정의 원본 해상도 파일을 구별한다. 하위 에이전트의 이미지 카드가 사용자 대화에 자동 전달된다고 가정하지 않는다. 각 요청 역할마다 현재 적용되는 필수 조건과 기본 스타일 제외를 충족한 시도의 경로를 선택한다. 적합한 시도가 없으면 최종 선택 없음(NONE)과 미해결 사유를 기록한다. 제외·실패·미선택 시도는 원본과 이력에 보존하고, NONE인 역할도 요청 수량과 미해결 분모에 남긴다. 적합한 이전 결과를 유지할 수 있으며 보정본을 새 역할로 세거나 한도를 초기화해 수량을 채우지 않는다.

최초 생성 전에는 자기 방향의 실제 이미지·공간·글자·본문 흐름을 짧은 제작 명세로 해결한다. 레퍼런스를 다시 열었다는 기록이나 출처별 대응표는 일반 제작의 필수 산출물이 아니다. 추가 자료를 실제로 조사한 경우에만 유용한 아이디어를 간단히 축적하고, 열람하지 않은 원본을 봤다고 주장하지 않는다. 사용자 보존 자산·수정 대상의 실제 참조와 아이디어 자료의 역할을 구별한다. 자신의 의도나 자기 점수로 실제 이미지 검수를 대신하지 않는다.

## 전체 다섯 장 확인

중앙은 모든 결과를 직접 보고 카피·조건을 대조한다. 나란히 놓인 실제 이미지에서 스타일의 정체성이 뚜렷한지 확인한다. 같은 좋은 읽기 순서와 정렬 자체를 다양성 실패로 보지 않는다. 가장 약한 시안도 같은 기준으로 본다. 겹치거나 미완성인 방향은 남은 보정 한도 안에서 해당 제작자에게 위치·원인·바꿀 관계·유지할 장점을 지정한다. 같은 이미지를 두 작업자가 동시에 수정하지 않는다. 중앙의 추가 호출도 같은 이미지의 이력에 합산한다.

해당 이미지에 기본 스타일 제외가 적용되면 [동일한 제외 구성](art-direction.md#기본-스타일-제외)을 실제 결과와 대조한다. 계획에 사진·그림이 적혀 있거나 제작자가 "다른 스타일"이라고 설명해도 위반을 통과시키지 않는다. 단순 폰트 교체로 종결하지 않으며, 남은 한도 안에서 전체 관계를 재설계하고 한도 이후의 미해결을 그대로 알린다. 이전 결과를 유지하는 선택에도 현재 적용되는 제외를 확인한다.

각 역할의 성공·실패와 최종 경로 또는 NONE의 대응을 확인한 뒤 적합한 선택본만 완성 시안으로 전달하고 미해결 역할 수와 사유를 알린다. 중앙은 선택한 원본 파일과 현재 사용자 대화에서 사용할 이미지·파일 참조를 확보하고, [최종 답변 전달](../SKILL.md#5-파일과-전달)에 따라 적합한 포스터 각각을 답변 안에 표시하며 바로 아래에 해당 원본 다운로드 링크와 실제 픽셀 크기를 제공한다. 제작자의 내부 경로나 완료 설명만 받아 적는 것으로 전달을 끝내지 않는다. 실패한 역할은 남은 범위에서 이어 수행하고, 한도·도구 문제나 미해결 결함은 숨기지 않는다. 일부 우수 결과 때문에 나머지를 생략하거나 미선택 보정본을 다른 스타일로 세지 않는다.
