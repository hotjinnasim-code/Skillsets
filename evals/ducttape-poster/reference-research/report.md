# 확장 레퍼런스 연구

공식 100 Beste Plakate 2024·2025 아카이브에서 기사당 한 이미지 200개를 전체 구도 수준으로 관찰했고, 그 안의 8개를 원본 크기로 추가 열람했다. 자체 관찰은 전체 아이디어 100개·부분 아이디어 86개·제외 구성 14개를 구별한다. 수상 여부를 자동적인 품질 승인으로 쓰지 않았다.

스튜디오 후보 41개 중 실제 내려받아 본 이미지 37개는 전체/부분 포스터, 제외 반례, 지원 매체와 미확인을 구별했다. 시리즈 중복을 묶은 유효 포스터 작품/시리즈는 20그룹이며 19그룹이 전체/부분 아이디어, 1그룹은 제외 반례다. 작은 원본·프로젝트 대응 불확실성도 남긴다. 두 조사 단위가 다르므로 독립 작품 220개나 독립 스튜디오 148개라고 합산하지 않는다. Canva는 별도 대중적인 행사 식별과 안내 묶음의 부분 참고다.

구성·이미지 표현·크롭·색·정보·글자·마감을 현재 내용에 변형할 아이디어로 축적했다. [현재 구성 문법](../../../skills/ducttape-poster/references/design-grammar.md)과 [선택적 참조 색인](../../../skills/ducttape-poster/references/reference-catalog.json)에 연결한다. 일반 요청마다 새 웹 조사나 원작 재열람을 의무화하지 않는다.

연구 이미지와 콘택트시트는 로컬 연구용으로 보존하며 이 새 보관에는 출처 이미지·글꼴 바이너리를 복사하지 않았다. 과거 평가 보관의 출처 이미지까지 없다는 주장은 하지 않는다. 이 명시적 부분 보관은 실제 시각 열람을 독립적으로 재구성하는 완전한 재생 패키지가 아니다. 스튜디오 완료의 빈 reports 등록과 실제 하위 output_dir 보고서, 초기 내려받기와 후기 관찰 상태의 차이를 원문 그대로 유지했다. 추가 웹 발견은 새 시각 관찰 0개이며 U/V 제작 입력으로 쓰지 않았다. 출처 수와 명성은 생성물의 하이엔드 품질·폰트 적용·AI 제작 주체 판별을 입증하지 않는다.
