# R24 첫 제작을 위한 다섯 방향 설계

현재 LIVE AB와 R24-C1의 원래 요청·두 카피·조건·자산·수량·비율·스타일·역할을 그대로 보존했다. 이번 한 요청의 다섯 방향만 작성했으며 M1/M2는 16:9, M3–M5는 2:3이다. 새 케이스·작업·이미지·렌더·평가는 만들지 않았다.

R23 초기 관찰에서 이름 붙인 비사진 표현도 같은 카메라식 거리·문턱의 재질 처리로 모였던 원인을 고려해, 각 native_positive_brief를 **형태·경계·세부·빛의 구현 규칙 → 실제 카피 한 벌의 의미 단위 줄바꿈 → 장면·색·마감·필수 조건**으로 작성했다. 원본 copy 필드는 그대로이고 네 줄 본문의 soft 줄바꿈을 도구 명세 안에 직접 넣었다. 고정되지 않은 어절 공백만 표시 줄바꿈으로 바꾸며 카피를 원문 전체나 그룹 JSON으로 다시 붙이지 않는다. 제목만이나 다른 카피량에 이 네 줄을 일반화하지 않는다.

- M1은 한 사진의 가까운 유리·먼 불빛·반사된 보행을 서로 다른 초점과 시간으로 묶는다. 연속된 반사광의 큰 사선이 화면을 조직한다. M5의 여러 관찰 조각 편집과 달리 한 광학 공간의 거리 차이를 보인다.
- M2는 소리의 넓은 굽은 밴드, 연결된 종아리·신발의 세 보행 순간, 단단한 창 빛의 면으로 구성한다. 선명한 색면과 열린 간격이 실제 표현이며 사진에 인쇄 질감을 입히는 지시가 아니다. M3의 암부·절개와 달리 유색 곡선과 연속 동작의 넓은 리듬이다.
- M3은 검은 연결 덩어리를 밝은 절개로 파서 창·전선·발 흔적을 만든다. 두 색 경계와 밀도가 모든 묘사를 결정한다. M2와 평면·읽는 축을 공유해도 장면의 구성 원리와 긴장감은 다르다.
- M4는 보행 중 위를 본 지붕·전선·매달린 천·창 빛을 불투명한 큰 붓 움직임으로 만든다. 상하의 하늘 열림이 카피를 잇는다. M3과 명조를 공유할 수 있어도 넓은 획의 방향·겹침·낮빛이 전체를 구성한다.
- M5는 코트의 접힘·손이 닿은 손잡이·천에 남은 빛을 큰 두톤 추출과 국소 망점으로 편집한다. 같은 현실 장면의 표면 필터가 아니라 서로 다른 관찰 거리·접촉 조각의 크롭과 맞물림이 새로운 전체 이미지를 만든다.

다섯 스타일의 실질적인 차이가 우선이다. 각 방향에 반드시 서로 다른 레이아웃·서체·팔레트·매체를 하나씩 주는 메뉴는 만들지 않았다. 넓은 네 줄 본문과 좋은 시작축은 공유한다. 큰 고딕 정보판에 작은 이미지를 붙이는 기본 템플릿, 클레이·장난감의 관습을 출발점으로 쓰지 않으면서 사진·고딕·여백을 범용 금지하지 않는다. 카피의 실제 역할은 Title과 body뿐이다.

## 가로 두 방향에만 선택한 새 own guide 명세

M1/M2의 guide_spec는 기존 renderer 계약의 canvas/shapes/text_blocks만 포함하며, directions의 guide_geometry_concept는 도형이 맡는 내용·표현·공간 관계를 설명한다. 도형은 실제 사진이나 생성된 포스터의 입력·편집이 아니라 새 자기 저작 계획 재료다. 아직 렌더하지 않았고 PNG를 본 것으로 주장하지 않는다. 다른 세 방향에는 guide/guide_spec가 없다.

가로 스케치의 본문은 기존 설치된 Apple SD Gothic Neo Medium(index 2), source 46 em·baseline 66, 넓은 1070×288 영역의 네 줄로 먼저 잡았다. 첫 본문 줄의 영역 시작은 y582이다. 제목은 96 em으로 명조(M1) 또는 같은 고딕 골격의 Semibold(M2)를 선택했다. 짧은 제목은 무게·명도·여백으로 즉시 인지되게 하며 본문을 크게 잡았다고 자동으로 확대하지 않는다. 1600×900 source와 usage720은 이번 알려진 읽기 상황의 설계 가정이고 전역 font/pixel/ratio floor가 아니다. 폰트의 실제 몸체·속공간·획을 참고하는 계획이며 em·bounds fit·font 이름으로 편한 읽기나 최종 font-file 적용을 보증하지 않는다. 문단 주위 작은 선·물체를 글자처럼 붙이지 않고 주요 밝은 경계와 동작 도형은 그 바깥에서 읽는 열림을 만든다.

M3–M5의 direct 명세에도 본문이 화면 폭 대부분을 쓰는 연속 네 줄의 설명 문단이라는 형태를 넣고, 각 표현의 거친 절개·붓질·망점을 활자에 번지게 하지 않는다. 제목의 주된 앵커를 유지하면서 실제 본문 면적과 이미지 크롭을 함께 설계한다. 없는 부제·eyebrow·안내·footer는 추가하지 않는다.

축적한 이미지의 초점 차이·큰 면과 작은 세부 밀도·연속 동작·여러 거리의 편집 아이디어를 재사용했다. 새 웹이나 원본 작품을 열지 않았으며 특정 작가·원작을 결과 한 장의 답안으로 배정하지 않는다. 작품 수나 source ID를 품질 증거로 쓰지 않는다. R24는 닫힌 R23의 같은 요청을 사용하는 알려진 개발 fixture이며 held-out 검증이나 두 optional guide만의 독립적인 인과 실험으로 주장하지 않는다.

작성 범위는 이 plan.json과 rationale.md 두 파일뿐이다. LIVE·helper·work/round24·원기록·평가 기준은 변경하지 않았다. 파일 필드·역할·비율과 원문/표시 카피의 어절·문장부호 보존만 기계적으로 확인했다. 실제 guide 렌더·첫 native 제작·결과 판단은 아직 수행하지 않았다.
