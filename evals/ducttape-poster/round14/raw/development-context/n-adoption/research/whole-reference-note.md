# N 전체 스타일 조사 · 실제 관찰과 적용 범위

실제 원본5개를 보았다. Version Industries 한 스튜디오의 서로 다른 프로젝트3개와 Canva 템플릿2개이며, 다섯 독립 스튜디오나 모두 적합한 완성 기준으로 세지 않는다. 모든 파일의 실제 바이트·크기와 공개 출처는 acquisition JSON에 있고 원본 보기 기록은 root-actual-reference-views.json에 있다. 고객 자산이 없으며 연구 원본을 native 생성에 고객 자산으로 넘기지 않는다. 아래 관찰과 현재 요청에서의 해석을 구별한다.

[Version Industries 공식 포스터 작업](https://versionindustries.com/work/tag/poster)에서 다음 전체 관계를 확인했다. Protomen은 극단적인 전경 부츠 크롭과 작은 원경 인물, 강한 잉크 명암·붉은 바탕이 하나의 장면을 만들고 작은 정보와 윤곽 제목이 경계를 쓴다. Anne at 13,000 feet는 얼굴 표정·높이·방향의 변화를 이어 붙인 비균등 사진 띠가 큰 빈 공간을 조직하고 세로 제목이 그 움직임에 대응한다. Grandfather Puzzle은 두 규모의 인물 윤곽·사진·붓 흔적이 페이지 전체를 조직하며 제목과 크레딧은 다른 역할을 맡는다. 이 이미지들은 다른 장르·내용의 포스터다. 실제 인물·로고·손글씨 문서·크롭을 복제하지 않고 현재 건축 사진전과 공간 이야기의 관계를 새로운 장면·편집·그림에서 설계한다. 필수 문구 없는 장식 문자는 이식하지 않는다. 이것을 기본 빈티지 질감 목록으로 바꾸지 않는다.

[Canva Street Portraits](https://www.canva.com/templates/EADanxXm868-street-portraits-collage-poster/)는 큰 회색 제목·정보 면에 좁은 세 사진 열을 붙인다. 글꼴이 세리프여도 이 텍스트 판형을 새 기본 방향으로 가져오지 않는다. 사진의 거리·시간 변화와 행사 정보의 묶음은 관찰할 수 있다. [Canva Brown Photography Workshop](https://www.canva.com/templates/EAHHiPe0HXM-brown-simple-photography-workshop-poster/)은 어두운 단색에 희미한 빛 번짐, 큰 고딕 제목·일정·안내 격자와 작은 인물 사진을 얹는다. 이는 새 제외 기준의 우회 예시이며 하이엔드 기본 스타일로 전달하지 않는다. 안내의 목적·대상·일정·행동이 구별되는 전달 원리만 취한다. 두 Canva 전체 평면 미리보기6을 브라우저에서 선택했고 편집·로그인·구입하지 않았다. 다운로드 실제1131×1600은 화면 natural1200×1697과 구별한다.

전체 참고는 폰트만의 수집이 아니다. 현재 한글 카피·16:9 매체에서 이미지 표현, 거리·크롭, 색·빛, 공간·정보·글자·정서를 함께 새로 해결한다. 큰 색 면의 존재 자체와 수동적인 바탕 위의 제목·정보 판형 지배를 구별한다. 대중적 전달이 된다는 이유로 사용자 제외를 해제하지 않는다. 모든 레퍼런스가 AI 없이 제작되었다거나 새 결과가 통과한다고 주장하지 않는다.
