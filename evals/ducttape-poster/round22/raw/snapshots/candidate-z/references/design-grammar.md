# 내용에서 고르는 전체 구성 문법

레퍼런스에서 축적하는 것은 완성 판형이 아니라 **내용·이미지 편집·공간·글자가 함께 작동하는 선택**이다. 아래의 22개 관계는 필요할 때 선택적으로 쓰는 발상의 출발점이다. 위에서부터 우선 적용하는 스타일 순위나 매번 하나씩 고르는 다섯 가지 메뉴가 아니다. 현재 내용에 맞는 관계를 선택·변형·결합한다. 원작의 이미지·카피·로고·색 조합·고유 배열을 이식하지 않는다. 일반 제작에서 원본을 매번 다시 읽을 필요는 없다.

## 스타일에 맞는 읽는 관계를 고르기

현재 내용에 맞는 스타일의 정체성을 먼저 구체화한다. 이미지의 표현·편집, 색·대비, 타이포그래피의 목소리, 재질·마감과 정서가 함께 만드는 전체 인상을 선택하고 실제 카피가 자연스럽게 읽히는 구도로 구현한다. 사진·판화·회화 같은 재료 이름만 나열하지 않고 무엇을 어떤 거리·크롭·형태·빛·표현으로 보여 줄지 적는다. 고급 레퍼런스의 이미지 표현·색·밀도·글자·재질·정서와 읽는 관계 모두가 아이디어가 될 수 있다. 아래의 연속 장면·여러 장면의 편집·반복·집합·도해·공유 경계는 선택 가능한 관계이며 모든 스타일의 공간 구조를 다르게 만드는 의무가 아니다.

각 방향의 명세는 실제 전체 인상이 그려질 만큼 구체적이면 된다. 같은 잘 읽히는 Title·body 순서와 정렬을 공유해도 이미지 표현·편집, 색·서체의 목소리·마감·정서가 뚜렷한 다른 체계로 결합하면 독립 스타일이 될 수 있다. 필터나 글꼴 하나의 교체로 그 차이를 대신하지 않되, 고유한 다섯 레이아웃·첫 카피 역할·정보 순서·팔레트·서체 수량을 요구하지 않는다. 제작자가 배정된 스타일과 실제 카피에 맞는 구도를 선택한다.

## 축적한 관계와 현재 내용으로의 전환

| 관계 아이디어 | 현재 내용에서 설계할 것 | 실제 관찰의 예와 이식 한계 |
| --- | --- | --- |
| 반복 동작이 시간과 경험을 만든다 | 행동의 변화·관점·간격을 실제 내용에서 선택하고 연속 행의 열림에 관련 안내를 넣는다. 거대한 한 사물이 없어도 장을 구성할 수 있다. | BP2024-038의 여러 사람 동작, BP2024-074의 집합 이동. 원작 사람·동작 수·격자는 복제하지 않는다. |
| 두 장면 사이 편집이 의미를 만든다 | 서로 다른 순간·거리·시점을 왜 연결하는지 정하고, 경계에서 설명·일정으로 이동한다. | BP2024-009, BP2024-078. 원작의 캡션을 옮기거나 도해 선으로 본문을 덮지 않는다. |

| 이미지와 글자가 같은 실루엣을 공유한다 | 대상의 윤곽·절개·겹침이 어떤 단어 묶음을 열거나 연결할지 정한다. | BP2025-004, BP2024-015, BP2025-053. 필요한 글자·상품 특징은 가리지 않는다. |
| 그래픽 움직임이 읽기 통로를 만든다 | 선·면의 방향과 실제 설명·일정의 정렬을 하나로 설계한다. | BP2025-029, BP2025-089. 화살표·측정 눈금·가짜 치수를 장식으로 추가하지 않는다. |
| 의미의 관계가 도해의 연결을 만든다 | 실제 과정·대조·분류·연결만 시각화하고 해당 설명을 가까운 안정된 묶음으로 둔다. | BP2025-013, BP2024-025, BP2024-070. 근거 없는 인과·경로·스펙을 만들지 않는다. |
| 여러 작은 서사 장면이 전체 인상을 만든다 | 장면마다 무엇을 보여 주는지, 각 설명이 어느 행동에 속하는지 정한다. | BP2025-047, BP2024-058. 모든 주제를 만화로 바꾸거나 무관한 캐릭터를 넣지 않는다. |
| 대화·몸짓과 카피가 짝을 이룬다 | 설명의 질문·조건·행동이 실제 카피에 있을 때 가까운 이미지와 읽는 역할을 연결한다. | BP2025-021, BP2025-047. 새 말풍선 카피·번호·소제목을 발명하지 않는다. |
| 사진·그림·도해의 묘사 차이가 발상을 만든다 | 각 표현이 맡을 정보와 만나는 경계·스케일·대비를 정한다. | BP2024-010, BP2025-091, BP2024-086. 재료 이름을 나열하는 콜라주로 끝내지 않는다. |
| 짧은 대상 크롭의 반복이 감각을 전달한다 | 현재 내용과 관계있는 부분·표정·구조를 여러 거리로 편집한다. | BP2025-070, BP2025-052. 원작의 귀·눈을 일반 감각 장식으로 가져오지 않는다. |
| 실물의 구조가 글자 역할을 만든다 | 연결·접힘·매달림·표면의 열린 곳과 실제 카피의 기능을 대응시킨다. | BP2024-053, BP2025-062. 긴 본문을 곡선·원근·접힌 작은 면에 억지로 조판하지 않는다. |
| 장면의 모순이 한 사건의 정서를 만든다 | 현재 내용에 근거한 두 환경·대상의 만남을 선택하고 카피는 그 사건의 읽는 경계에 둔다. | BP2024-011, BP2024-069. 글자를 놓을 빈 방이나 임의 초현실 사물을 만들지 않는다. |
| 색과 초점이 이미지의 정서를 바꾼다 | 무엇을 또렷하게, 흐리게, 차갑게, 뜨겁게 보여 줄지 내용에서 결정한다. 실용 안내의 대비는 별도로 확보한다. | BP2025-065, BP2025-072, BP2024-012. ‘시네마틱’·흐림·필름 입자만으로 디자인을 대신하지 않는다. |
| 거친 이미지와 정밀한 안내가 함께 간다 | 그림의 획·인쇄 흔적은 이미지의 역할에 사용하고 본문은 안정된 글자 골격·간격·정렬로 둔다. | BP2025-082 원본의 거친 분홍 선과 정교한 상단 안내, BP2024-013의 사물 사진과 프로그램 표. 이미지 질감을 작은 본문에 씌우지 않는다. |
| 실제 프로그램이 조판의 단위를 만든다 | 날짜·시간·출연자·장소가 같은 행/그룹에 속하는 관계를 그대로 살려 읽게 한다. | BP2024-013, BP2024-099. 일반 설명 문단을 이유 없이 표로 바꾸지 않는다. |
| 같은 내용의 다른 스케일이 비교를 만든다 | 큰 설명과 작은 세부의 역할을 분명히 하고 각각의 카피가 해당 대상에 붙게 한다. | BP2025-035, BP2024-085. 큰 전체 이미지+작은 하단 안내를 공통 틀로 삼지 않는다. |
| 양음 형태가 제목과 이미지의 공간을 공유한다 | 면을 자르거나 겹쳐 생긴 열린 공간을 실제 어절·본문 묶음과 연결한다. | BP2025-024, BP2024-089. 수동 색면에 작은 도형만 보태지 않는다. |
| 다국어의 형태 차이가 하나의 축에 모인다 | 언어·숫자·기호의 광학 크기와 무게를 맞추고 역할별로 같은 시작점·간격을 쓴다. | BP2025-042, 한국 스튜디오의 다국어 안내. 라틴의 자간·낱자 분해를 한글 문장에 그대로 적용하지 않는다. |
| 원문 문장의 의미가 본문 그룹을 정한다 | 하나의 설명은 이어 읽는 문단으로, 다른 방문 조건은 찾을 수 있는 다음 그룹으로 둔다. 이미지의 연속·방향·공유 경계가 두 그룹을 연결하게 한다. | BP2024-077의 연속 설명, BP2025-082의 기능별 안내. 모든 정보를 사진의 빈 모서리마다 나누지 않는다. |
| 친숙한 행사 식별과 개성 있는 표현이 함께 간다 | 사람에게 필요한 행사 종류·기간·장소·참여 조건을 명료하게 묶고 현재 이미지 문법과 결합한다. | Canva는 정보 묶음과 방문 판단의 보조 자료다. 제목·날짜·사진 템플릿이나 장식 가득한 기본 틀은 가져오지 않는다. |

숫자는 조사 기록의 식별자다. 이 목록이나 레퍼런스 규모를 포스터 품질 점수로 사용하지 않는다. 같은 관계도 내용·언어·비율·카피량이 달라지면 새로 설계해야 한다. 참고 작품이 좋은 전체 발상을 가진 경우에도 원작의 작은 글자·낮은 대비·가림·특수 폰트까지 답안으로 채택하지 않는다.

## 본문을 처음부터 읽게 만드는 면적과 글자

긴 설명을 작은 캡션으로 취급하지 않는다. 현재 표시 크기에서 읽힐 본문 몸체·줄 폭·행간을 먼저 잡고, 실제 문장의 어절과 줄 수가 들어갈 면적을 이미지·제목과 함께 확보한다. 예를 들어 가로 720px로 보는 디지털 포스터의 설명은 약 14–18px 정도의 또렷한 본문 몸체를 출발점으로 생각할 수 있다. 원본이 1672px 폭이면 대략 33–42px에 해당한다. **매체·서체·내용에 따른 설계 예시이며 고정 품질 문턱이나 새로운 사용자 픽셀 조건이 아니다.** 글자 크기만으로 판독을 보장하지 않고 광학 형태·줄 폭·간격·배경 대비를 함께 설계한다.

본문 공간이 부족하면 이미지의 거리·크롭·편집과 조정 가능한 제목의 비중부터 바꾼다. 본문을 전부 좁은 하단이나 원근이 심한 사물 면에 밀어 넣지 않는다. 그림·콜라주를 선택한 경우에도 본문은 잘 완성된 인쇄 활자처럼 정밀한 별도 평면 조판으로 설계할 수 있다. 같은 한글 자소의 폭·속공간·획 연결, 라틴·날짜의 기준선, 문단 시작축·행간을 일관되게 유지한다. 모든 요청에 고정 글꼴 목록·정보 패널·다섯 레이아웃 메뉴를 강요하지 않는다. 적합한 읽기 구도는 여러 스타일에서 공유할 수 있다.
