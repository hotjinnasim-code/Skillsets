# 내용에서 전체 시각 체계로

좋은 포스터는 이미지가 멋지고 글자가 정확한 것에서 끝나지 않는다. 내용, 이미지의 선택과 크롭, 색상, 정보의 큰 덩어리, 글자의 비례와 세부 간격이 하나의 판단을 보여야 한다. 레퍼런스의 폰트만 빌리고 나머지를 생성 모델의 기본 구성에 맡기지 않는다.

## 발상과 전체 구조

먼저 현재 내용에서 관객이 알아야 할 것과 느껴야 할 것을 찾는다. 제목만 있으면 그 말의 관계·상태·행동에서 시각적 발상을 정하고, 주어지지 않은 사실은 만들지 않는다. 안내가 길면 실제 참여 정보의 그룹과 필요한 면적부터 정한다. 특정 소재를 골랐다는 사실만으로 발상이 해결됐다고 하지 않는다.

각 방향의 첫 시선, 그다음 필요한 정보, 지배적인 글자 역할과 이미지·글자의 경계를 함께 정한다. 반복 공식의 우선순위를 낮추는 것은 큰 글자·강한 색을 모두 약하게 하라는 뜻이 아니다. 작은 제목과 차분한 정보만으로 다섯 장을 획일화하지 않는다.

발상을 눈에 보이는 관계로 바꾼다. 등장 요소가 어떻게 연결·반복·변형·접촉·비교되는지, 어디에서 장면이 잘리고 글자나 정보가 그 경계를 어떻게 사용하는지 정한다. 명료한 직접 표현도 허용한다. 억지 은유를 만들거나 모든 주제를 장식적인 한 오브젝트로 대체하지 않는다.

하나의 행사·과정·경험에 속한 여러 행동을 함께 보여 줄 때는 각 행동의 식별과 함께 공유·연속·대비 등 원문에 있는 관계도 구성에서 읽히게 한다. 공통 대상·공간·시선·반복·경계 같은 단서를 현재 내용과 표현에 맞춰 선택하며, 떨어진 장면이면 그 관계가 어디서 이어지는지 확인한다. 실제로 분리된 활동을 합치거나 주어지지 않은 시간 순서·인물을 만들지 않고, 사용자 지정 분리·배치·시점을 우선한다.

화면에서 어떤 대상·행동이 다른 대상이나 결과를 만들어 내거나 바꾸는 관계를 보여 줄 때는 함께 등장한다는 사실과 실제 대응의 근거를 구별한다. 현재 발상을 성립시키는 핵심 특징과 의도적으로 달라지는 특징을 먼저 정하고, 실제 이미지의 양쪽을 그 기준으로 대조한다. 연결·분리, 주요 부분의 배치, 경계·방향 등 필요한 특징은 시점·크롭·반사·변형·추상화의 차이를 고려해 확인하며, 같은 색·질감이나 대략적인 모양만으로 대응을 통과시키지 않는다. 사용자가 지정하지 않은 내부 특징의 수나 모양은 그 관계를 구현하는 수단이다. 실제로 다른 특징이 필요한 대응을 보여 준다면 계획값을 맞추려고 고치지 않는다. 표현상 확인되지 않는 작동은 추정으로 남기고 표면의 밝고 어두움만으로 물리적 오류를 단정하지 않는다. 이 관계가 필요 없는 구성에 새 과정·인과·물리 장면을 추가하지 않는다.

읽는 순서는 내용에 따라 달라진다. 제목이 첫 시선일 수도 있고 사진의 사건·날짜·반복되는 정보 구조가 첫 시선일 수도 있다. 각 방향마다 실제 카피의 중요도, 제목의 단어 묶음과 폭, 장면의 식별, 안내의 판독을 함께 조정한다. 모든 장에 큰 제목을 상단, 주제 오브젝트를 중앙, 나머지 카피를 하단에 놓는 공통 틀을 쓰지 않는다. 의도를 장황하게 설명하는 것으로 화면에서 모호한 관계를 보완하지 않는다.

출력 비율마다 큰 덩어리와 실제 카피의 점유 면적을 함께 검토한다. 여러 주요 블록이 같은 강도로 경쟁하거나 프레임·구조가 안내의 자리를 밀어내면 우선순위와 면적을 다시 배분한다. 필수 정보를 판독이 어려운 작은 글자로 좁은 칸에 밀어 넣지 않는다. 큰 글자나 무거운 구조가 필요한 경우에도 다음 정보까지 읽는 경로와 충분한 안내 면적을 확보한다.

계획 설명을 판독의 근거로 삼지 않고 축소 보기에서 실제 첫 앵커와 경쟁하는 큰 요소를 짚는다. 사용 크기에서는 관객이 현재 목적에 필요한 카피 전체를 찾는 경로를 실제로 따라가며, 다음 목적지로 이동하게 하는 화면 단서를 확인한다. 필수 정보가 여러 구역에 있으면 각 항목의 판독과 전체 정보를 찾아 쓰는 흐름을 구별한다. 선택한 첫 역할과 다음 유용한 정보가 이어지지 않거나 무관한 구역을 반복해서 훑어야 하면 그룹·강약·공간 관계부터 고친다. 제목·이미지·날짜나 의도한 여러 진입점 모두 가능하며, 한 정보 패널·열이나 고정된 제목→일정 순서를 강요하지 않고 사용자 지정 순서를 우선한다.

## 레퍼런스가 바꿔야 하는 결정

확인한 작품의 전체 체계에서 현재 내용에 필요한 원리를 고른다. 다음 항목을 함께 보고, 실제 설계에서 서로 영향을 주게 한다.

| 차원 | 실제 설계에서 정할 것 |
| --- | --- |
| 이미지 표현과 스타일 | 사진·그림·조형의 표현 체계, 장면·행동·대상의 관계와 식별 |
| 시점과 크롭 | 관객과 대상의 거리, 프레임 밖으로 이어지는 요소, 중요한 사건을 보이는 경계 |
| 레이아웃과 공간 | 큰 덩어리의 상대적 면적·무게, 기준선·인접·접촉·빈 공간·순서 |
| 색상 | 배경·주제·글자 사이의 대비와 우선순위, 색이 맡는 정보·정서 역할 |
| 타이포그래피 | 실제 단어 묶음, 비례·무게·폭·간격, 이미지 경계와 기준선의 관계 |
| 정보 계층 | 제목·일정·장소·행동 안내의 그룹과 읽는 순서, 축소와 사용 크기의 차이 |
| 재질과 제작 방식 | 빛·표면·경계·흔적의 일관성, 사진·인쇄·물성의 선택 이유 |
| 정서와 대상 | 강도·친근함·낯섦의 필요, 보는 사람이 해석하고 참여할 수 있는 정도 |

원작의 문구·브랜드·캐릭터·특정 구도를 옮기지 않는다. 원작의 선택이 현재 한글의 길이·수량·정보량에서 깨지면 새로 설계한다. 질감이나 포스터 목업을 붙여 제작의 흔적을 위장하지 않는다. 원작이 극단적인 크롭·삭제·반복을 썼더라도 확정 카피의 누락·변형·중복을 허용하지 않는다.

## 다섯 방향의 실제 구분

각 방향의 내부 계획은 짧되 제작 가능한 수준이어야 한다. 내용의 핵심, 전체 표현 체계, 구체적인 장면과 크롭, 실제 카피 그룹과 상대적 비중, 글자와 이미지의 관계, 색·재질·정서를 적는다. 고정 좌표나 같은 비율 할당을 모든 방향에 강요하지 않는다. 제작자는 실제 카피를 보고 이 관계를 구체화한다.

가장 가까운 다른 방향과 두 가지로 비교한다.

- **표면을 가린 비교:** 색·재료·효과 이름을 지웠을 때도 큰 형태와 글자·정보의 위치·역할이 다른가? 같은 제목 스택·주제 한 덩어리·하단 정보라면 재료가 달라도 겹친 방향이다.
- **실제 내용의 비교:** 이 제목·문구·사건 때문에 선택한 구조인가? 다른 행사 이름으로 바꿔도 대부분 그대로라면 현재 내용의 이미지 관계와 정보 우선순위에 맞는지 다시 본다. 관련 행사에 재사용 가능한 격자나 시각 체계도 현재 요청을 충분히 해결하면 유효하다. 모든 요청에 유일한 은유나 인간의 행동을 강요하지 않는다.

구분을 만들려고 사용자 조건을 버리지 않는다. 같은 장르 안에서도 장면의 조직, 시점, 정보의 그룹, 글자 역할과 공간은 달라질 수 있다. 명시한 사진·3D·보색·클레이 표현을 유지하면서 가능한 차이를 찾는다. 다섯 장을 통일된 캠페인으로 묶으라는 요청이 없으면 공통 팔레트·폰트·레이아웃을 덧붙이지 않는다.

## 기본 스타일 제외

제외하는 구성은 **단색·거의 단색·분할 색 면을 수동적인 바탕으로 두고 고딕 제목·일정·안내 블록의 판형이 전체 인상을 지배하며 이미지가 부가물에 머무는 템플릿**이다. 무채색·유채색 모두 실제 전체 관계로 판단한다. 희미한 질감·노이즈·그라데이션·격자, 작은 삽화나 독립된 하단 이미지 띠를 더했어도 그 관계가 그대로면 제외 구성이다. 제목이나 전체 글꼴만 세리프·손글씨 등으로 바꿔 같은 판형을 제시하는 우회도 통과시키지 않는다. 고딕 제목·안내 자체, 모든 단색 여백이나 모든 타이포그래피 중심 작품을 금지하는 기준은 아니다. 다른 실제 이미지·공간·글자 관계가 전체 인상을 만드는 구성에서는 고딕을 쓸 수 있다.

이는 제작 주체 판별이 아니라 사용자가 거부한 기본 구성의 제외 조건이다. 현재 적용되는 명시적 사용자 지시로 해당 전체 구성을 요구한 경우에만 해당 이미지·요청 범위에서 해제한다. 조사·계획·최초 및 수정 명세·실제 검수·선택은 같은 정의와 적용 여부를 사용한다. 일반적인 미니멀·모던·깔끔, 고딕 글꼴 지정이나 글자만의 요청은 전체 구성의 해제가 아니다. 글자만의 요청은 비문자 요소 요구만 해제하며 다른 타이포그래피·공간 관계로 해결한다. 사용자 지시를 다시 승인받는 절차는 만들지 않는다.

이를 피하려고 다섯 장 모두 사진 배경·세리프·빈티지 질감으로 통일하지 않는다. 실제 레퍼런스에서 장면의 거리와 편집, 그림의 표현 체계, 이미지의 경계와 연속, 정보가 들어가는 공간을 내용에 맞춰 설계한다. 각 방향은 **이미지·공간·글자의 전체 인상**이 달라야 하며, 고딕을 쓰더라도 같은 굵은 제목·날짜·안내 패키지를 다섯 장에 반복하지 않는다. 사용자가 비문자 요소를 제외하지 않은 경우에는 글자 판독을 보장하면서 비문자 시각 체계가 내용과 인상을 실질적으로 맡게 한다.

## 반복되는 생성 습관의 우선순위 낮추기

열린 스타일에서는 둥근 두꺼운 클레이 한글, 강한 보색, 장난감 같은 덩어리의 조합을 먼저 고르지 않는다. 큰 오브젝트와 큰 제목을 포개고 작은 정보만 아래에 붙이는 반복도 낮춘다. 내용과 무관한 크롬·홀로그램·블롭, 빛나는 그라데이션과 임의 입자·별·테이프·종이 조각을 완성도의 대용으로 쌓지 않는다.

이 기준은 장르 금지가 아니다. 지정한 표현이나 내용에 필요한 효과는 구현한다. 강한 색·입체·과감한 크롭도 구체적인 구조가 해결되면 좋은 선택이다. 반대로 무채색·세리프·거친 종이·넓은 여백이 저절로 고급스러운 것은 아니다. 대중적인 요청에서 알아보기 쉬운 그림, 친근한 색, 직접적인 정보 배치는 존중하되 범용 템플릿의 장식까지 자동으로 가져오지 않는다.

## 실제 결과의 일곱 기준

| 기준 | 이미지에서 확인할 것 |
| --- | --- |
| 내용과 형태 | 현재 내용의 관계·행동·정보가 설명 없이 보이고 주요 선택을 연결하는가 |
| 정보 계층 | 첫 시선이 분명하고 필수 정보까지 읽는 순서·그룹·대비가 이어지는가 |
| 타이포그래피 | 정확한 한글과 카피, 단어·줄 묶음·비례·간격이 이미지와 함께 설계됐는가 |
| 공간 | 크롭·무게·여백·정렬·접촉·경계가 큰 관계와 세부에서 의도적인가 |
| 이미지와 재질 | 대상의 구조·행동·빛·접촉·표면이 표현 체계 안에서 일관되는가 |

| AI 슬롭 방지 | 반복 공식·임의 장식·붙인 글자·가짜 세부·합성 결함이 결과를 지배하지 않는가 |

축소·사용 크기·원본에서 모두 본다. 한글은 획의 연결과 단어 간격, 선명도·대비, 줄 끝과 경계를 함께 본다. 작은 정보를 예쁜 점무늬로 처리하거나 정확한 카피를 읽기 어려운 구석에 넣지 않는다. 실제 손·접촉·물체 기능·로고를 요청한 경우 확인한 원본과 대조한다. 구도·위치·비례 보존 요청은 대상의 경계와 상대 위치·크기·크롭을 같은 비율에서 비교한다. 모양과 색이 닮았어도 대상이 이동·축소됐다면 보존 문제로 남긴다. 스타일만 참고한 자료에 원작 위치 보존을 강요하지 않는다.

접촉·잡기·지지 동작이 있는 장면에서는 누가 무엇을 잡거나 받치며 각 손·부품이 어디로 이어지는지 먼저 정한다. 겹치는 접촉은 경계와 소유 관계가 읽히게 설계한다. 사진을 잉크·평면·입체 등 다른 표현으로 바꾼 뒤에도 손·접촉면·대상의 구조를 다시 확인한다. 명암 축소나 질감 추가로 불분명한 연결을 가리지 않으며, 요청한 행동과 필요한 복잡성을 유지한다.

시간 범위의 대시, 콜론, 숫자처럼 혼동하기 쉬운 작은 기호는 글자 비례·기호의 형태·획·광학 간격을 함께 설계한다. 대시와 하이픈처럼 가까운 모양은 원문 기호의 구별되는 길이·위치·주변 획과의 관계가 실제 사용 크기에서 남는지 확인하고, 원본에서도 다시 본다. 다른 기호로 교체하거나 사용자가 고정한 공백을 바꾸지 않고 크기·비례·대비·공간 관계로 판독을 개선한다. 래스터의 모양으로 원래 Unicode 코드 포인트를 인증하지 않으며 남은 판독 불확실성은 기록한다.

사용자가 글자만의 구성이나 비문자 요소 제외를 명시하지 않은 경우에는 비문자 요소가 핵심 발상을 맡는지 보되 크기가 크다는 이유로 인정하지 않는다. 작은 장식·배경 질감·글자 조형만 남으면 발상과 구조를 다시 설계한다. 장면이나 구조가 이미 충분한 경우 빈자리를 오브젝트로 채우지 않는다. 사용자가 글자만의 구성이나 이미지 제외를 명시하면 그 조건 안에서 발상·글자·공간을 평가한다.

보정은 실제 결과에서 영향이 큰 원인을 우선한다. 사용자 보존 조건 위반을 제외하면 계획 좌표에서 벗어났다는 사실보다 내용의 핵심 관계와 실제 정보 검색의 실패를 먼저 본다. 필수 조건 → 읽기·구성 → 글자·이미지 마감 순서로 실패 위치, 깨진 관계, 다음 결과에서 확인할 변화와 보존할 장점을 짧게 정한다. 보정 뒤에는 같은 보기에서 그 관계를 전후 대조하고 전체 카피·조건·정보 경로도 다시 확인한다. 재질·접촉·질감이 좋아져도 필요한 대응이나 읽는 흐름이 남으면 미해결로 기록한다. 같은 국소 지시로 관계가 해결되지 않았고 호출이 남아 있으면 사용자 조건과 방향의 구분을 지키며 필요한 시점·경계·그룹·비중까지 재설계한다. 최신 파일이나 더 매끈한 표면을 자동 채택하지 않고 전체 내용·판독·마감을 더 잘 유지한 결과를 선택한다. 한도를 소진한 미완성은 그대로 알리며 하이엔드라고 단정하지 않는다.

전후 비교에는 **목표 변화**와 **기존 장점에 생긴 변화**를 실제 위치와 관찰로 짧게 남긴다. 원본의 표면·경계, 사용 크기의 정보 연결, 축소의 큰 비중을 같은 보기에서 대조하며 바꾸지 말라고 지시한 영역도 실제로 확인한다. 축소에서 가려지는 새 표면 무늬·윤곽 변화나 국소 마감으로 해결되지 않은 전체 관계를 계획 달성의 이득으로 덮지 않는다. 의도한 거침·비대칭·분산 정보·내부 크롭은 내용과 표현 체계 안에서 역할과 연결이 유지되는지 판단하고 특정 마감이나 격자로 통일하지 않는다.

AI 슬롭은 특정 색·매체의 목록이나 제작 주체를 알아맞히는 검사가 아니다. 화면의 구체적인 구성·글자·재질·내용 적합성에 대한 판단이다.

명시된 기본 스타일 제외와 AI 슬롭 점수는 별도로 확인한다. 사용자가 제외한 구성이 남으면 그 조건 위반을 기록하며, 일곱 품질 점수·카피 정확도·다른 시안의 장점으로 상쇄하지 않는다. 아직 제외 기준이 없었던 과거 결과의 점수를 사후에 덮어쓰지 않는다.
