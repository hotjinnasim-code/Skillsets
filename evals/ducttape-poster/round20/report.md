# R20 / W — 실제 카피와 내용 형태를 먼저 설계한 다섯 방향

R19 전체 평가를 닫은 뒤 같은 식물 마켓 원문·12개 카피·조건·16:9 비율·빈 사용자 자산을 보존해 한 요청의 다섯 장을 제작했다. 복합 본문과 안내가 있는 요청은 사용 가능한 기존 런타임에서 실제 카피·폰트와 내용의 실질적인 이미지 형태를 첫 생성 전에 함께 스케치하는 W 일반 지침을 먼저 고정했다. 사용자 자산은 없으며 중앙이 새로 만든 독립 스케치 다섯 개를 각 제작자에게 자기 것만 제공했다. 축적한 디자인 아이디어를 사용하고 조사 원본을 매 제작자에게 다시 열도록 요구하지 않았다. 스케치는 클라이언트 구도 보존 조건이나 최종 중립 스타일이 아니며, 최종 이미지는 네이티브 도구로 제작했다.

다섯 제작자의 네이티브 호출은 9회, 반환 9회, 실패 0회다. 보정 호출은 4회이며 최초본 선택은 2개, 보정 없이 최초본으로 종료한 역할은 2개다. 실제 최대 세 작업자로 논리적 다섯 역할을 실행했다. 보정본은 새 스타일로 세지 않는다.
