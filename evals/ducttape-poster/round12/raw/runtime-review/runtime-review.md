1. **Make user precedence explicit at the structural-diversity gate.** [SKILL.md:34](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/SKILL.md:34), [art-direction.md:46](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/references/art-direction.md:46) and [evaluation-loop.md:60–62](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/references/evaluation-loop.md:60) require structural diversity without locally addressing a deliberately identical layout, fixed reading path or requested campaign system. There is already controlling precedence: [art-direction.md:49](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/references/art-direction.md:49) forbids abandoning user conditions for distinction, [SKILL.md:50](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/SKILL.md:50) preserves requested composition, and [parallel-production.md:9](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/references/parallel-production.md:9) says the central plan is not an added user condition. Thus this is a gate-level ambiguity rather than an established production blocker. Clarify that distinction is pursued within permitted degrees of freedom, intentional shared structure is reported honestly, and any evaluation scope for constrained variants is declared before execution. Do not claim five structurally distinct systems when the request intentionally prevents them, or retroactively relax an agreed diversity gate.

2. **Separate portable design systems from unsuitable generic ideas.** [SKILL.md:58](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/SKILL.md:58) lists “내용이 바뀌어도 그대로 쓸 범용 발상” as a slop cause. The latter supplies the necessary nuance, but the short checklist could be applied too broadly. Qualify the failure as inadequate adaptation or content mismatch, rather than portability alone. This preserves reusable event, public-information and template systems without rewarding arbitrary decoration.

3. **Declare rubric applicability for intentionally absent elements.** [SKILL.md:14,36](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/SKILL.md:14) permits text-free and explicitly typography-only outputs; [art-direction.md:75](/Users/nahyeonbin/Desktop/_Codex/ducttape-poster-round12/snapshots/candidate-l/references/art-direction.md:75) evaluates typography-only work within that condition. This is an evaluation applicability ambiguity, not an observed failure. State the treatment before evaluation so reviewers do not fabricate evidence, force unwanted elements, or confuse deliberate omission with unavailable evidence.
