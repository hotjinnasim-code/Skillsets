# R17 / T — 새 생활수리 요청의 다섯 장

방대한 레퍼런스 연구를 22개의 구성 아이디어와 선택적 출처 색인으로 통합한 T를 고정하고, 이전에 만들지 않은 생활수리 워크숍 한 요청의 한국어/영문 카피 12개로 16:9 다섯 장을 제작했다. 다섯 독립 제작자와 실제 최대 세 동시 작업자를 구별한다. 네이티브 호출 13회가 모두 반환했고 한 역할은 최초를 유지했으며 네 역할은 보정 두 번을 사용했다.

여섯 새 평가 세션은 모두 종료했으며 두 단계의 절차·입력 결속·해당 원본 확인 감사가 통과했다. 최초 다양성은 editorial 3, craft 3, portfolio 2이며 선택은 모두 3이다. 선택 M3의 시간 구분 기호가 한 평가자에게 원본 재확인 뒤에도 불확실해 문자 조건과 타이포그래피 하나가 NA다. 이 null을 새 점수로 채우거나 평가자를 교체하지 않았다.

주요 실패는 제목·설명·행사/참여 두 묶음이라는 카피 구조가 다섯 이미지 표현 위에 반복되는 점이다. 일부 실제 문구의 역할이 계획에서 암시로 남았고, 문단의 실제 형태를 정하지 않아 한 줄의 긴 설명이나 끝 동사만 남는 줄이 생겼다. 가장 선명한 최초 결과도 다른 세 평가자의 공간·정서 판단에 차이가 남았다. M5는 최초 비율이 사전 반올림 허용 밖이었으며 선택에서는 비율을 충족했지만 수동 형태의 정보판과 경쟁하는 굵은 글자의 문제가 남았다.

이 자료는 처음부터 모든 시안이 강하다는 증거가 아니다. 다운로드·레퍼런스 관찰 수를 산출물의 품질로 바꾸지 않았다. 다음 일반 지침은 이미지와 실제 글자 덩어리를 함께 설계하고, 보조 언어·슬로건·행사 이름의 역할과 문단의 실제 줄 묶음을 선택하도록 개선한다. 글자·면적의 새로운 계획 스케치를 선택적으로 참고하는 방법은 별도 초안이며 아직 포스터 품질 효과를 인증하지 않았다. 같은 현재 이미지에는 평가 뒤 수정이나 재선택을 하지 않았다.
