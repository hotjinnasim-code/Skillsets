# 한 요청의 첫 다섯 장을 위한 설계 초안

R19-C1의 원문 요청과 12개 표시 문구를 그대로 유지한 디자인 계획이다. 생성이나 평가를 시작하지 않았다. 기존 포스터, 평가 파일·점수, 원작 이미지, 웹 자료를 열지 않고 V 초안의 축적한 아이디어와 현재 요청에서 출발했다.

이번 내용의 핵심은 작은 화분과 오래 기른 식물 사이에서 고르는 즐거움, 집의 빛과 생활에 맞추는 판단, 마켓 방문에 필요한 실제 정보다. 다섯 방향을 먼저 다른 전체 이미지 조직과 실제 글자 덩어리의 관계로 나눈 뒤 그 관계에 맞는 재료를 골랐다.

| 역할 | 전체 장의 관계 | 첫 글자 앵커와 다음 읽을 곳 | 표현 체계 |
| --- | --- | --- | --- |
| M1 | 불균등한 사진 크롭의 대각 접점 | 좌하단 제목 → 중간의 넓은 설명 → 오른쪽 크롭 경계의 방문·행동 열 | 카메라 표면과 자연색, 정밀한 명조 제목·고딕 본문 |
| M2 | 사람이 함께 있는 연속 시장 테이블 | 좌상단 슬로건 → 테이블 열림의 설명 → 테이블 끝의 방문·행동 열 | 간결한 인물, 강한 선과 따뜻한 평면색, 휴머니스트 본문 |
| M3 | 여러 식물 실루엣이 여는 두 연결 통로 | 위쪽 날짜·행사·시간·장소 → 왼쪽 설명 → 가까운 오른쪽 입장·관리·행동 | 비대칭 종이 절개 군집; 전체 식물 구조가 여백을 결정 |
| M4 | 다른 높이의 독립 표본이 여는 하나의 읽기 열 | 행사·일정 → 같은 축의 설명 → 바로 아래 입장·관리·초대·URL | 관찰적인 색연필·잉크와 정확한 책 조판; 식물의 높이와 경계가 열 주변을 조직 |
| M5 | 세 개의 불균등한 회화 장면과 중앙 캡션 접점 | 중앙 초대 → 설명 → 같은 축의 아래 방문·관리·URL | 짙은 실내빛과 제어된 붓 면, 장면 편집, 정밀한 평면 본문 |

M1과 M5는 편집된 여러 이미지가 들어간다는 점이 가깝지만, 대각 접점에서 위로 갔다 오른쪽으로 도는 제목 중심 구조와 중앙 캡션에서 아래로 이어지는 초대 중심 구조로 구분했다. 사진과 회화의 차이에만 기대지 않는다. M2도 사람과 생활이 등장하지만 분리된 장면 편집 대신 하나의 연속 테이블과 가로 방향 관계를 사용한다. M3은 식물 군집이 여는 두 공간 사이를 건너가고, M4는 독립 식물 표본이 여는 하나의 열을 읽는다. M4와 M5가 모두 아래로 이어지는 부분이 있어도, 식물 표본 주변의 한 열에서 행사·일정을 먼저 만나는 구성과 회화 장면 사이의 캡션 접점에서 초대를 먼저 만나는 구성으로 구분했다.

긴 설명은 어느 방향에서도 이미지의 남는 자리에 작은 캡션으로 넣지 않는다. 실제 문장을 의미가 이어지는 3–5줄로 미리 나누고 충분한 문단 면적, 성숙한 한글·라틴·숫자 형태, 자연스러운 어절 간격과 행간을 정했다. 각 문단의 끝에서 다음 실제 안내의 시작으로 이어지는 인접, 공유하는 수평 선, 실제 이미지 경계 또는 짧은 수직 전환을 명시했다. 한 안내 문장을 여러 그림 모서리에 나누지 않는다.

날짜가 먼저인 M3, 행사·일정이 먼저인 M4, 초대가 먼저인 M5에서는 제목·라틴·슬로건을 보조 역할로 낮춰 여러 헤드라인이 경쟁하지 않게 했다. 다른 방향에서도 보조 라틴과 슬로건을 다른 구석의 강한 헤드라인으로 만들지 않는다. 정보 묶음이 비슷할 수 있어도 실제 위치·이미지 경계·진입점·연속 관계가 다르게 작동하도록 설계했다.

720px 너비의 SNS 보기는 내부 설계 가정이다. 새 고객 픽셀 조건이나 새로운 합격 문턱으로 쓰지 않는다. 줄 묶음도 기능하는 실제 결과를 계획 좌표에 맞추기 위한 보정 요구가 아니다. 실제 이미지의 판독과 전체 구분은 아직 검증하지 않았으며 계획만으로 고품질을 선언하지 않는다.

이 다섯 방향은 현재 식물 마켓 요청을 해결하기 위한 선택이다. 스킬의 영구적인 다섯 스타일 메뉴, 매번 필요한 원작 대응, 새 가이드 의무, 추가 검수 절차를 만들지 않는다. 제목·본문·안내를 포함한 완성 포스터 한 장을 각 제작자가 기본 내장 이미지 도구로 직접 처음부터 만드는 계획이다. 부모 작업이 R18 전체 평가의 종료를 확인한 뒤에만 새 제작을 시작할 수 있다.
