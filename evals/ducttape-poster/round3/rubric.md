# 이미지 평가 기준

각 원문의 필수 문구·수량·비율·스타일·대상 조건을 실제 원본에서 먼저 대조한다. 문구가 틀리거나 추가·누락됐으면 시각적 강점과 별개로 기록한다. 한글·숫자·영문·URL이 애매하면 원본을 다시 보고 불확실성을 남긴다. 지정하지 않은 줄바꿈은 어절 경계에서 허용한다. 이미지로 실제 제품 용량이나 제작 주체를 증명했다고 말하지 않는다.

버전·생성 순서·제작자 명세를 추측하지 않고 이미지와 원문으로 판단한다. 1은 미해결, 3은 기능하는 결과, 5는 매우 잘 해결된 결과이고 2와 4는 그 사이이다. 각 점수에 보이는 위치·선택·영향의 근거를 둔다. 점수를 합산하거나 평균으로 구체적인 약점을 덮지 않는다.

| 항목 | 3: 기능하는 결과 | 5: 매우 잘 해결된 결과 |
| --- | --- | --- |
| 내용과 형태 | 주제는 반영하지만 일부 선택이 임의적 | 구체적 발상이 주요 선택을 연결하며 설명 없이도 설득력 있음 |
| 정보 계층 | 중심과 읽는 순서가 보임 | 첫 시선부터 필수 안내와 행동까지 자연스럽게 연결 |
| 타이포그래피 | 읽기와 그룹화가 합리적 | 획·어절·비례·크기·간격·배치가 이미지와 하나의 구성으로 작동 |
| 공간 | 균형과 정렬이 일관됨 | 크롭·무게·여백·접점의 큰 관계와 작은 관계가 의도적 |
| 이미지·재질 마감 | 표현 체계가 대체로 일관됨 | 형태·빛·재질·경계가 발상과 제작 방식에 맞게 정교함 |
| 정서와 제어 | 요청에 맞는 정서와 요소 | 절제든 과잉이든 정확하고 각 요소에 역할이 있음 |
| AI 슬롭 방지 | 일관되지만 범용적 습관이 남음 | 내용에 특화된 편집·글자·공간·재질이 설득력 있고 두드러진 합성 결함이 없음 |

AI 슬롭 방지는 제작 주체 식별이 아니다. 상투적인 효과·소품의 패키지, 가짜 미세 문자, 어색한 한글, 따로 붙은 글자, 무차별 질감, 빛·원근·구조의 혼란을 실제 위치와 영향으로 판단한다. 스타일을 맡긴 경우와 효과를 명시한 경우를 구별하되 어느 장르도 자동 감점하거나 가산하지 않는다. 크롬·네온을 명시한 요청에서 그 표현이 없으면 조건 위반이다. 미니멀·아이보리 종이·거친 인쇄라는 이유만으로 높은 점수를 주지 않는다.

세트 다양성은 별도 평가한다. 3은 구분되지만 구조적 습관이 남는 경우이고 5는 각 방향의 글자 역할·구성·이미지 표현이 공통 조건 안에서 설득력 있게 나뉘는 경우다. 색이나 표면만 바꾼 경우 1–2에 해당한다. 독립 대안 스타일이므로 캠페인 통일성을 요구하지 않는다.

축소(긴 변 320px)는 첫 시선, 화면 사용 크기(너비 720px)는 정보 판독, 원본은 글자·경계·재질에 사용한다. 인쇄 적합성은 이번 검사에서 확인하지 않는다. 모든 결과의 실제 원본을 본다. 세부 정보는 원문의 존재만이 아니라 화면 크기에서 판독돼야 한다.

최고 시안과 가장 약한 시안을 함께 기록한다. 내용과 형태·타이포그래피·마감·AI 슬롭 방지 각각 4–5의 실제 근거, 필수 조건 통과, 다양성 4–5를 이번 하이엔드 후보의 최소 신호로 본다. 다른 항목의 구체적 미해결 문제도 남긴다. 평가자 간 차이와 불확실성은 그대로 기록한다. 이 소수 사례로 모든 사용자 요청의 성공률을 인증하지 않는다.
