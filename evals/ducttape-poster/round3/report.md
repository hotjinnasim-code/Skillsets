# 덕테이프 포스터 추가 평가 — 2026-10-07

실사용 기본 다섯 장을 서로 다른 다섯 제작자가 한 장씩 맡는 구조로 바꾸고, 내용과 기능에서 스타일을 고르는 지침을 보강했다. 한 제작자의 결과를 다음 제작자의 기준 이미지로 이월하지 않는다. 실제 도구 한도가 낮으면 가용 작업자부터 실행하며, 이 환경의 한도는 중앙 포함4명, 제작자 동시 최대3명이다.

**전체11장이 모든 평가자의 하이엔드 최소 신호를 통과했다고 판정하지 않는다.** 정원과 요청한 강한 효과에서는 선택한 모든 시안의 핵심 항목에4–5 근거가 있지만, 모집과 제품에는 구체적인3점 또는 평가자 차이가 남았다. 이 결과를 완전한 AI 슬롭 제거 인증으로 포장하지 않는다. 스킬은 같은 약점을 실물 결과에서 찾고, 남은 보정 범위에서 고치며, 해결되지 않으면 실제 문제와 선택 파일을 밝히도록 강화했다.

## 검증과 원자료

스킬 생성기의 `quick_validate.py`, YAML 파싱, 스킬의 상대 링크, 고정한6파일의SHA-256,34개 실제 생성 결과/축소본의 파일 대응·픽셀·해시, 이미지별 보정 한도와 최종11개 선택을 검사했다. [최종 검증 결과](final-validation.json), [재실행 가능한 검증기](validate_evidence.py), [선택 전 독립 점검](reviews/evidence-audit-preselection.md)을 보존했다. 픽셀 비율은 사전에 정한 상대 오차1%를 적용했다.

레포에는 긴 변512px의 평가용 미리보기34개와 원본 해시·실제 크기·평가·스킬 사본을 저장했다. 미리보기는 원본 해상도나 사용 크기 검수를 대신하지 않는다. 실제 도구 원본·전체 내부 입력·생성 이력·720px/320px 검사본과 비교 갤러리는 작업 폴더 `../ducttape-poster-round3/`에 있다. 갤러리는 실제 파일과 링크를 확인했으며 브라우저 렌더링 검사를 수행했다고 주장하지 않는다.

## 판정 범위

비율 오차1%는 생성 전에 정한 조건이다.1122×1402는4:5 대비 약0.036% 오차로 통과하며, 한 평가자의 정확한 정규화 제안은 이 조건의 실패로 세지 않는다. 생성 모델에는 크기 인자가 없어 프롬프트만으로 최대 해상도나 특정 정수 픽셀을 보장하지 않는다.

AI슬롭 점수는 실제 상투적 구성·글자·빛·재질·경계에 대한 판단이며 제작 주체 식별이 아니다. 인쇄, 실제제품 용량, 모든 향후 사용자 요청의 성공률은 검증하지 않았다. 후보A와B는 실제 제작 구조까지 다르므로 스타일 우선순위 변경만의 인과효과를 분리한 실험이 아니다.
