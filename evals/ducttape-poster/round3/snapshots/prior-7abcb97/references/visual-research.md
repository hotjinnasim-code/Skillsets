# 시각 자료 조사

하이엔드 완성도·AI 슬롭 방지·적극적인 자료 활용을 요청받았거나 주제의 시각 언어가 불분명할 때 읽는다. 아래는 탐색의 출발점이며 고정 레퍼런스 세트가 아니다. 일반적인 요청을 조사만 하다가 끝내지 않는다.

## 조사에서 제작으로 연결하기

현재 내용·카피 밀도·매체·표현 제약과 관련된 실제 작품을 소수 확인한다. 서로 다른 제작 방식이나 타이포그래피 접근도 비교한다. 가능하면 디자이너·디자인 스튜디오·미술관의 원문과 실제 이미지를 보고, 검색 설명이나 재게시한 분위기 모음만으로 평가하지 않는다.

각 자료에서 **구성의 작동 원리, 글자와 이미지의 관계, 재질·제작의 일관성, 이 요청에 적용할 이유**를 짧게 내부 기록한다. 원문이 직접 설명하는 내용과 내가 작품을 보고 추론한 내용을 구별한다. 주제와 맞지 않는 취향은 가져오지 않는다.

자료 조사를 길게 프롬프트에 붙이거나 작품 이름만 나열하지 않는다. 확인한 원리를 현재 카피와 주제의 구체적인 크기·간격·형태·공간 관계로 바꾼다. 레퍼런스의 작품 정보·가짜 제작 표식·유명 로고를 장식으로 가져오지 않는다. 사용자가 특정 구도를 유지하라고 한 경우에는 그 요청을 우선한다.

연구용 이미지와 사용자가 준 필수 이미지, 수정 대상을 구분한다. 실제 이미지 파일을 도구에 입력하면 참조 역할과 유지·교체할 부분을 명시한다. 단지 URL을 읽었다고 생성 도구가 이미지를 보았다고 말하지 않는다. 자료 이미지 자체를 스킬의 출력용 자산으로 묶지 않는다.

## 확인한 자료와 적용 범위

2026-10-07에 확인한 1차 자료다. 웹·GitHub 내용은 바뀔 수 있다. 특정 스타일을 기본값으로 만드는 대신 필요에 맞는 원리를 확인한다.

| 자료 | 원문에서 확인한 내용 | 포스터에 적용할 판단 |
| --- | --- | --- |
| [Cooper Hewitt — How Posters Work](https://www.cooperhewitt.org/2015/02/05/cooper-hewitt-to-present-special-exhibition-how-posters-work/) | 구성·지각·이야기로 메시지를 전달하며 집중과 시각적 과밀 모두를 다룸 | 절제만을 품질로 보지 않고 주제에 맞는 시선과 경험을 설계 |
| [Cooper Hewitt — Making a Poster is a Process](https://www.cooperhewitt.org/2014/12/05/making-a-poster-is-a-process/) | Philippe Apeloig가 글자의 간격·무게·겹침을 조정하고 인쇄 재질을 함께 설계 | 타이포그래피와 질감이 각각의 효과가 아니라 같은 발상을 구현하는지 확인 |
| [Sulki & Min — Ungmang](https://www.sulki-min.com/wp/ungmang-banner/) | 제목의 의미에 맞춘 한글 형태 변형을 일정한 획 두께의 체계로 제작 | 한글 왜곡도 규칙과 주제가 있어야 함; 모든 글자를 변형하라는 기본값은 아님 |
| [Pentagram — Re-Source](https://www.pentagram.com/work/re-source) | 전시의 판매·모금 목적과 상업적 타이포그래피의 강한 표현을 연결 | 많은 서체·강한 효과도 실제 목적과 일관성이 있으면 유효; 표현만 복제하지 않음 |
| [Letterform Archive — Contemporary Design of South Korea](https://letterformarchive.org/news/contemporary-design-of-south-korea/) | 한국 스튜디오들의 포스터와 출판물을 맥락·작품 이미지와 함께 소개 | 한글을 영문 포스터의 치환으로 처리하지 않고 실제 한글 글자와 공간의 관계도 연구 |
| [Anthropic — frontend-design](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md) | 주제에서 조형을 도출하고 계획과 실제 결과를 비평 | 웹 UI의 기본 요소·폰트 금지 목록 대신 내용별 판단과 결과 검수를 적용 |
| [Anthropic — canvas-design](https://github.com/anthropics/skills/blob/main/skills/canvas-design/SKILL.md) | 최종 보정에서 기존 구성의 관계와 정밀도를 개선 | 수정은 효과 추가보다 관찰한 약점의 원인에 집중; 해당 스킬의 카피 축소 규칙은 가져오지 않음 |
| [IBM Carbon — typography](https://github.com/carbon-design-system/carbon-website/blob/main/src/pages/elements/typography/overview.mdx) | 크기·굵기·행간의 조합과 표현적·정보 전달용 글자 역할을 구분 | 제목과 안내의 상대적 계층을 설계; IBM 폰트·수치·색을 포스터 기본값으로 쓰지 않음 |

표의 오른쪽 열은 이 스킬을 위한 적용 판단이며 원문이 보장하는 평가 척도가 아니다. 원작 자료는 조사에 활용하며 자신의 생성 이미지를 원작 디자이너의 작업으로 표시하지 않는다.
