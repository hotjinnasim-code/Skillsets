# 선택적인 구성 가이드 구현 검증

새 SVG 도형·실제 문구와 그 PNG 보기를 만드는 보조 도구다. 기존 래스터 입력·반환 포스터 편집·폰트 다운로드·자동 레이아웃·품질 점수는 없다. 최종 포스터는 계속 내장 image_gen을 사용한다.

독립 통합 검토의 현재 작업 폴더 경계, 실행 위치와 cmap 보장 문제를 해결했다. 본문 없는 요청·실제 사용자 자료·좁은 스타일·구도 보존의 적용 범위도 별도 지침 검토에서 문제 없음으로 기록했다.

기존 v2의 17개 테스트 뒤, v3는 변경에 맞춘 회귀를 포함해 27개 테스트를 실행해 모두 통과했다. 현재 폴더에서의 독립 호출, cmap 불일치, OS/2가 없는 실제 한글 명조, 문구·줄바꿈·범위와 기존 파일 보존을 검사했다. 이 macOS 환경에서 명시한 두 글꼴만 확인했으며 다른 환경·최종 이미지의 폰트 파일 적용·포스터 품질을 입증하지 않는다. 원검토·원테스트 기록은 [색인](archive-index.json)에 그대로 보존했다.
