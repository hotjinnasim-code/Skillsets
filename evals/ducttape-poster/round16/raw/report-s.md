# R16 / S — 한 요청의 다섯 장 평가 완료

ONBIT 데스크 램프 체험전을 위한 장문 한국어 가로 16:9 요청 한 건을 다섯 독립 제작자가 수행했다. 실제 내장 이미지 호출은 14회였고 최초 다섯 장 모두 보정을 필요로 했다. 전체 결과를 고친 뒤 다른 요청으로 넘어가는 방식이 아니라, 최초 결과와 선택 결과를 각각 보존하고 독립 평가했다.

최초 평가는 원점수 105개를 보존했으나 portfolio 세션의 스트림 오류 때문에 절차 NA이며 다섯 이미지도 NA다. 선택 결과는 절차·입력 결속·제품 원본 확인 감사가 통과했고 원점수 105개를 보존했다. 기존 판정은 PASS 0, FAIL 3, NA 2이며 전체 세트 NA다. 세 평가자의 다양성 점수는 최초·선택 모두 3이다. NA를 통과나 실패로 다시 채점하지 않았다.

공통 실패는 제품을 왼쪽에 크게 두고 오른쪽에 제목·설명·일정·방문 정보를 놓는 구도로의 수렴이다. 사진·판화·회화·종이 재료를 바꿔도 전체 편집과 읽는 길이 충분히 달라지지 않았다. 본문은 큰 제목과 제품에 비해 작고 압축되었으며, 일부는 기울어진 페이지나 거친 표면에 들어가 표시 크기의 읽기가 약해졌다.

다음 지침은 특정 램프 이미지의 좌표를 고치는 대신, 전체 공간 조직을 재료보다 먼저 선택하고 실제 문장의 읽기 크기·폭·행간·면적을 먼저 확보하도록 개선한다. 거친 이미지와 정밀한 본문 조판은 함께 사용할 수 있다. 평가 문턱·원점수·불리한 기록은 유지한다. 이후 생성·재선택 없이 이 묶음을 닫았다.
