배정 방향 관계 명세
방향: 함께 수거하는 가로 모집 안내
핵심 관계: 해안에서 여럿이 함께 줍는 한 번의 공동 작업과, 참여자가 신청 전에 확인해야 할 일정·자격·제공/준비·취소/비용을 같은 가로 전개 안에서 이어 준다. 공동 수거는 주제 사진의 장식이 아니라 모집과 준비 안내를 연결하는 행동이다.
먼저 찾을 것: 먼저 해안 정화 참여자 모집임을 알아보고, 같은 주목 범위에서 11월 18일까지 신청 문장과 전체 URL을 찾는다. 제목의 정서와 신청의 실용성이 서로 경쟁하지 않게 한다.
글자·대상·공간 관계: 연속 사진 대신 공동 수거가 동시에 일어나는 하나의 그림 장면을 사용한다. 집게가 쓰레기를 집고 봉투로 이어지는 접촉과 해변의 작업 방향을 명확히 하며, 그 방향·경계·빈 공간이 제목에서 관련 안내 묶음으로 시선을 잇는다. 그림을 크게 붙인 뒤 나머지 10문구를 하단 띠에 보내지 않는다.
안내/행동 연결: 모집과 신청은 즉시 연결한다. 일정·시간·집결 장소·대상은 참가 가능 여부를 확인하는 묶음으로, 집게/봉투 제공과 개인 준비물은 같은 준비 판단으로, 우천 문자 안내와 무료/확인서 조건은 참여 결정에 필요한 제한으로 관계를 만든다. 문의는 신청과 닿게 둔다. 그룹 제목 없이 기존 문장의 간격·길이·무게로 구별하며 이 의미 묶음이 화면의 고정 순서를 뜻하지는 않는다.
실제 기능: 해변 정화의 실제 수거 행동을 식별할 수 있고, 행사일 11월 21일과 신청 기한 11월 18일을 혼동하지 않아야 한다. 원문을 보지 않고도 기한과 haram-wave.example/join을 읽을 수 있어야 하며 제공물과 개인 준비물을 서로 바꾸어 보이지 않게 한다.
긴 카피 판독: 가로 폭을 가장 긴 우천 문장과 준비물 문장이 자연스럽게 이어지는 데 쓴다. 먼저 전체 안내가 읽힐 행 길이·행간·대비를 확보하고 남는 공간에서 그림 규모를 결정한다. 12개 문구 전체가 너비 720px 보기와 원본에서 판독되어야 하며 작은 하단 고지로 압축하지 않는다.
가까운 다른 방향의 추상적 의도: 다른 최종 방향은 해안 현장의 집게로 쓰레기를 봉투에 넣는 연속 사진과 세로 안내 읽기를 결합한다.
차별성: 다른 방향의 연속 사진은 수거 동작을 시간 순으로 보여 주고 세로 안내로 이어진다. C02는 한 장면의 공동 작업과 신청·준비 판단을 가로에서 함께 연결한다. 먼저 찾는 정보, 문구가 작업 경계를 따라 하는 역할, 신청과 조건 사이의 가까운 관계가 다르며 비율·색·크롭 차이로만 구분하지 않는다.
제작자가 정할 것: 인물 수와 표현, 관찰 시점, 수거 방향, 제목과 신청의 상대 비례, 안내의 구체 배치를 결정한다. 그림은 문장 판독을 침범하지 않게 조절하고 모든 안내를 특정 구획에 고정하지 않는다.

Codex 내장 image_gen을 실제 호출한다. 현재 도구 스키마와 지침을 따른다. API 키·SDK·CLI 이미지 생성으로 우회하거나 지원하지 않는 인자를 만들지 않는다.
신규 이미지에는 referenced_image_paths와 num_last_images_to_include를 모두 생략하고 transparent_background=false로 둔다. 다른 방향의 이미지나 프롬프트를 참조하지 않는다. 한 호출은 배정 포스터 한 장을 위한 독립 호출이다.
국소 보정은 해당 역할 원본을 실제 열어 본 뒤 현재 지원되는 참조 방식으로 전달한다. 모든 보정에도 전체 카피와 필수 조건을 다시 명시한다. 원인을 기록하고 수정 항목과 보존 항목을 구분한다.
이미지의 카피를 외부 프로그램으로 합성하여 생성 결과를 대신하지 않는다. 도구가 반환한 실제 파일을 보존하고 저장한다. 파일이 없거나 저장이 실패하면 실제 상태를 보고하며 존재하지 않는 파일을 저장했다고 주장하지 않는다.
원본·보정 선택을 비교한다. 최신 결과를 자동 채택하지 않는다. 확인할 수 없는 최대 크기를 얻기 위해 추가 생성하지 않는다.

실행 한도
최초 생성 1회 + 보정 최대 2회 = 이 이미지의 호출 최대 3회. 재생성도 보정에 포함한다. 추가 제작자 0명. 스킬 변경 0회. 다른 최종 방향 추가 생성 금지.

실제 결과 검수
실제 이미지를 축소·사용 크기·원본에서 본다. 축소에서는 첫 시선과 방향 관계, 사용 크기에서는 전체 카피 판독과 안내/행동 경로, 원본에서는 한글 획·기호·간격·정렬·경계·대상 구조·재질을 확인한다.
전체 필수 카피를 실제 이미지에서 전사해 원문 값과 대조한다. 가장 긴 문장과 가장 작은 필수 문구를 먼저 읽는다. 제목과 URL만 통과하고 나머지 조건을 미세 문자로 두는 결과는 통과하지 않는다.
문구·조건 위반, 읽기와 구성, 글자·이미지 마감 순으로 수정한다. 국소 문제는 해당 원본 보정, 핵심 관계나 판독 실패는 같은 배정 방향에서 재설계한다. 카피 삭제나 장식 추가로 숨기지 않는다.
주제와 무관한 범용 효과, 가짜 미세 문자, 불규칙한 한글, 따로 붙은 제목, 원근·광원·재질 불일치, 우연한 접촉·후광을 실제 위치와 영향으로 기록한다. 특정 사진·그림·색·서체·효과만으로 통과나 탈락을 정하지 않는다.
검수 기록은 실제 관찰과 파일에 대응한다. 자기 점수나 제작 의도를 관찰의 대체로 쓰지 않는다. 해결되지 않은 결함과 판독 불확실성, 확인한 화면 크기와 검증하지 않은 범위를 보고한다. 계획 단계와 실제 생성·검수를 구분한다.
