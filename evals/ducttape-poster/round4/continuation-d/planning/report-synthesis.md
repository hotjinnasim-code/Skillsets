## 근거가 지지하는 범용 원칙과 마지막 검토

1. 핵심 제목·사진·캡션만으로 주제 관계가 해결됐다고 보지 말고, 제공된 전체 카피와 독자의 신청·도착·조건 확인·구매 흐름까지 면적·인접·정렬로 이어지는지 확인한다.
2. 같은 의미 수준의 본문은 의도된 폭·정렬·행간 체계를 공유하고, 다른 수준은 실제 중요도에 맞는 차이를 갖는다. 신청을 먼저 발견하는 것과 전체 참가 조건을 연속 확인하는 것을 모두 사용 크기에서 검토한다.
3. 제품 시점과 상태 비교는 주장하는 기능을 보이게 고르고, 동일 대상의 림·밑면·연결·두께·겹침·접촉과 광원을 확인한다. 픽셀의 그럴듯함은 실제 기능 인증이 아니다.
4. 보정은 사용자 조건과 잘 작동하는 관계를 보존하되, 원인에 포함된 자체 배치를 불변조건으로 잠그지 않는다. 내용 식별과 판독이 확보돼도 전체 카피가 기능상 끊기면 구성 원인으로 다룬다.
5. 대안 차이는 소재·색·매체 교체뿐 아니라 제목의 역할, 이미지 규모와 시점, 본문 묶음, 진입과 읽는 경로에서 확인한다. 익숙한 장르·보통 서체도 내용에 맞게 작동하면 유효하다.

[기존 원작 조사와 출처 기록](../../research-findings.md)은 이러한 관계 편집과 기능 시점 원칙을 뒷받침한다. 특정 장르·색·서체·템플릿 목록, 필수적인 새로움, 변형 글자의 의무는 지지하지 않는다. 조사 원작은 생성 참조나 복사 재료로 쓰지 않았으며 출처의 공식 게시도 제작 주체 인증이 아니다.

마지막 D 보정은 새 **집중 독립 리뷰**가 필요하다. 실제로 바뀐 세 이미지와 영향받은 현재 세트·이전 같은 슬롯을 같은 기준으로 검토하고, 익명 사용 이미지의 선행 판독을 유지해야 한다. 유지된 C 열한 장은 선택된 실제 파일의 SHA-256을 기존 독립 근거와 정확히 연결해야 한다. 새 파일에 이전 점수를 상속하거나 현재 D6 실패를 지우지 않는다. 최종 스킬 상태·전체 품질 판정·선택을 닫기 전에는 각 선택 파일과 해당 리뷰의 정확한 해시 결합이 필요하다. 여섯 가상 요청의 화면 결과에서 모든 미래 요청의 품질·인간 제작 여부·실물 기능·인쇄 적합성을 주장할 수 없다.
