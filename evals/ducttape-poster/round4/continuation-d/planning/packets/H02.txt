배정 방향 관계 명세
방향: 조건을 읽고 가져올 것을 판단하는 수리 모집
핵심 관계: 수리 작업실의 핵심은 물건을 완성해 주겠다는 약속이 아니라 작은 생활용품을 가져와 상태를 함께 확인하고 가능한 수리를 결정하는 참여이다. 초대와 반입 제한·부품 비용·완성 보장 제한을 한 읽기 관계로 묶어, 정사각 화면 자체가 참여자가 가져올 물건과 신청 여부를 판단하는 안내로 작동하게 한다.
먼저 찾을 것: 먼저 고쳐 쓰는 토요일과 참여자 모집을 알아본 뒤, 자신이 가져올 작은 생활용품이 대상인지와 수리의 범위를 바로 확인한다. 신청 기한/URL도 이 판단과 이어지는 주요 신호로 보여 숨겨진 끝부분을 찾게 하지 않는다.
글자·대상·공간 관계: 이웃 여러 명의 공동 수리 장면을 중심에 두지 않는다. 편집된 원문 문장들의 길이·인접·행간이 큰 형태를 이끌고, 작은 비전기 생활용품 한 점의 느슨한 연결부를 상태 점검하는 간결한 시각 단서가 그 판단을 보조한다. 확인 도구와 연결부의 실제 접점은 보이되, 완성된 물건 전후 비교나 조건별 소품·아이콘 모음으로 전체 구성을 대신하지 않는다.
안내/행동 연결: 작은 생활용품 반입과 전기·배터리/위험 물건 제외를 직접 비교해 읽게 하고, 도구 제공/부품 비용과 수리 여부/완성 보장 제한은 같은 실제 수리 범위로 이어 준다. 일시·입장 시간·장소·연령/정원은 참석 가능성을 판단하는 관계로, 촬영 동의·참가비/현장 결제는 참여 방식으로 드러낸다. 12월 2일까지 신청 문장과 문의는 그 판단에서 행동으로 넘어가는 접점이다. 기존 문구만으로 구별하고 추가 그룹 제목은 넣지 않는다.
실제 기능: 수리의 보장이 아닌 상태 확인과 협업 참여라는 역할이 실제 카피와 시각 단서에서 읽혀야 한다. 행사일 12월 5일, 입장 오후 1시 40분, 진행 오후 2시–5시, 신청 기한 12월 2일을 구별한다. 전체 URL을 읽어 신청할 수 있고 반입 제외·현장 부품 비용·완성 보장 없음·촬영 동의가 쉽게 확인되어야 한다.
긴 카피 판독: 가장 긴 수리 여부는 상태 확인 후 결정하며 완성을 보장하지 않습니다. 문장이 자연스럽게 이어질 공간을 먼저 확보한다. 정사각 폭에서 문장을 무리하게 한 줄로 압축하지 말고 의미/어절 단위로 줄을 나누며, 같은 안내 역할의 문장끼리 행간·간격·대비를 조절한다. 14개 문구 전체를 너비 720px와 원본에서 읽는다. 전체 조건을 하단에 미세 문자로 몰아넣거나 점검 물건 때문에 남는 좁은 칸에 채우지 않는다.
가까운 다른 방향의 추상적 의도: 다른 최종 방향은 이웃의 나무 생활용품 공동 수리 그림과 초대·도착·하단 전체 조건을 결합한다.
차별성: 다른 방향은 나무 생활용품을 이웃이 함께 수리하는 그림에서 초대·도착을 읽고 전체 조건은 하단으로 이어진다. H02는 상태 확인과 반입/수리 범위 문장이 처음부터 참여 판단을 조직하고, 긴 문장들이 구성의 주요 무게를 가진다. 간결한 점검 단서는 이 판단에 종속되므로 같은 공동 작업 그림의 정사각 크롭이나 장면+하단 고지 구조가 아니다.
제작자가 정할 것: 구체적인 작은 비전기 생활용품과 점검 표현, 문장 묶음의 비례·정렬·줄 길이·간격, 제목/신청의 연결과 시각 단서의 위치를 정한다. 수리가 성공하거나 무료 부품이 제공되는 것처럼 보이지 않게 하고, 제목·도착·조건을 하나의 고정 수직 순서로 강제하지 않는다.

요청한 화면 비율을 유지하면서 현재 도구와 모델이 지원하는 가능한 최대 해상도로 출력. 실제 반환 너비·높이를 확인한다. 크기를 제어하는 지원 인자가 없으면 이 요구를 프롬프트에 넣고, 실제 최대 해상도 달성으로 단정하지 않는다. 확대 리사이즈를 원본 생성 해상도로 세지 않는다.

도구 주의
Codex 내장 image_gen을 실제 호출한다. 현재 도구 스키마와 지침을 따른다. API 키·SDK·CLI 이미지 생성으로 우회하거나 지원하지 않는 인자를 만들지 않는다.
신규 이미지에는 referenced_image_paths와 num_last_images_to_include를 모두 생략하고 transparent_background=false로 둔다. 다른 방향의 이미지나 프롬프트를 참조하지 않는다. 한 호출은 배정 포스터 한 장을 위한 독립 호출이다.
국소 보정은 해당 역할 원본을 실제 열어 본 뒤 현재 지원되는 참조 방식으로 전달한다. 모든 보정에도 전체 카피와 필수 조건을 다시 명시한다. 원인을 기록하고 수정 항목과 보존 항목을 구분한다.
이미지의 카피를 외부 프로그램으로 합성하여 생성 결과를 대신하지 않는다. 도구가 반환한 실제 파일을 보존하고 저장한다. 파일이 없거나 저장이 실패하면 실제 상태를 보고하며 존재하지 않는 파일을 저장했다고 주장하지 않는다.
원본·보정 선택을 비교한다. 최신 결과를 자동 채택하지 않는다. 확인할 수 없는 최대 크기를 얻기 위해 추가 생성하지 않는다.

실행 한도
최초 생성 1회 + 보정 최대 2회 = 이 이미지의 호출 최대 3회. 재생성도 보정에 포함한다. 추가 제작자 0명. 스킬 변경 0회. 다른 최종 방향 추가 생성 금지.

실제 결과 검수
실제 이미지를 축소·사용 크기·원본에서 본다. 축소에서는 첫 시선과 방향 관계, 사용 크기에서는 전체 카피 판독과 안내/행동 경로, 원본에서는 한글 획·기호·간격·정렬·경계·대상 구조·재질을 확인한다.
전체 필수 카피를 실제 이미지에서 전사해 원문 값과 대조한다. 가장 긴 문장과 가장 작은 필수 문구를 먼저 읽는다. 제목과 URL만 통과하고 나머지 조건을 미세 문자로 두는 결과는 통과하지 않는다.
문구·조건 위반, 읽기와 구성, 글자·이미지 마감 순으로 수정한다. 국소 문제는 해당 원본 보정, 핵심 관계나 판독 실패는 같은 배정 방향에서 재설계한다. 카피 삭제나 장식 추가로 숨기지 않는다.
주제와 무관한 범용 효과, 가짜 미세 문자, 불규칙한 한글, 따로 붙은 제목, 원근·광원·재질 불일치, 우연한 접촉·후광을 실제 위치와 영향으로 기록한다. 특정 사진·그림·색·서체·효과만으로 통과나 탈락을 정하지 않는다.
검수 기록은 실제 관찰과 파일에 대응한다. 자기 점수나 제작 의도를 관찰의 대체로 쓰지 않는다. 해결되지 않은 결함과 판독 불확실성, 확인한 화면 크기와 검증하지 않은 범위를 보고한다. 계획 단계와 실제 생성·검수를 구분한다.
