# 닫힌 R19의 일반 설계 원인

최초는 0 PASS / 5 FAIL / 0 NA, 선택은 1 PASS / 4 FAIL / 0 NA이며 전체 세트 FAIL이다. 두 단계 모두 절차와 기록 대응 검사는 PASS이고 각각 일곱 원점수 105개를 보존했다. 선택의 다양성은 세 평가자 모두 4로 높아졌지만 개별 완성도 기준이 남았다. M2만 모든 필수 조건과 각 평가자의 일곱 항목을 통과했다.

최초 단계는 매체가 달라도 식물이 연한 정보 영역을 둘러싸는 큰 관계와 일부 좌우 읽는 흐름이 가까워졌다. 여러 안내의 실제 크기가 작았으며 한 결과의 슬로건은 중복됐다. 선택 단계에서 그 중복은 없어졌고 전체 구분도 통과했지만, 다음 원인은 별도로 남았다.

- M1은 건강한 식물 전시만으로 선택·돌봄을 간접적으로 전달하며, 크게 보인 화분의 흐려진 지지/바닥과 서로 다른 스케일의 사진 결합이 설득력을 낮춘다는 portfolio 관찰이 남았다. 해당 평가자의 내용·이미지/재질·정서·AI 슬롭은 모두 3이다.
- M3은 무성한 식물 집합이 주된 발상이고 날짜·설명·서비스·작은 식별의 여러 글자 섬이 충분히 이어지지 않는다는 관찰이다. 장식체/매체 전면 금지의 근거가 아니라, 현재 내용의 관점과 실제 글자 묶음이 하나의 조직을 결정해야 한다는 설계 문제다.
- M4는 큰 설명 문단과 행사 식별의 경쟁, 짧은 가로 안내의 압축, 정원 같은 장면과 가정 식물 선택·돌봄의 약한 구체성, 뿌리가 노출된 용기의 컷어웨이/파손처럼 보이는 마감이 남았다. portfolio의 내용·이미지/재질·정서·AI 슬롭은 3이며 모든 평가자의 위계가 3이다.
- M5는 사용 크기에서 좁은 중앙 문단과 서비스·URL, 별도 작은 약속 문장이 편하게 읽히지 않는다. 문자 자체가 남았다는 사실과 사용 크기 판독은 구별된다.

여러 결과를 관통하는 다음 가설은 실제 내용을 보여 줄 관점·관계에서 시점·크롭·경계·이미지 조직을 고르고, 실제 활자와 카피 면적을 그 조직 안에서 먼저 구체화하는 것이다. 본문 크기만 키우거나 첫 문구/재료만 바꾸는 것으로 해결됐다고 보지 않는다. 특정 이미지의 화분·뿌리·식물·좌표를 다음 기본값이나 전면 금지로 만들지 않는다. 원작을 새로 다시 읽는 절차와 검수 문턱도 추가하지 않는다.

이 문서는 이미 닫힌 원점수의 일반화 기록이며 새 평가·재점수·선택 변경이 아니다. 다음 후보를 개발하면 새 지침과 전체 다섯 방향을 생성 전에 고정하고 이 버전의 모든 실패와 원본을 유지한다. 새로운 후보의 품질 증거는 아직 없다.
