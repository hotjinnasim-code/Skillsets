제안하는 런타임 문구는 다음 두 개다. 적용 위치는 아트디렉션의 계획→검수 연결과 제작자의 보정→선택 단계이며, 이 감사에서는 파일을 수정하지 않았다.

1. **계획을 관계의 가설로 사용한다.** 방향마다 사용자 스타일과 현재 내용에서 지킬 관계 한두 개를 적는다. 예: “거친 반복은 큰 형태를 묶고 안내는 찾아 읽을 수 있다.” 좌표·폰트·재료 상세는 이를 구현하는 수단이다. 사용자 보존 조건이 아닌 내부 숫자와 달라도 실제 관계가 성립하면 숫자 일치만을 목표로 보정하지 않는다. 여러 정보 구역·진입점·컷아웃도 각자의 역할과 연결 단서가 보이면 유지한다.
2. **수리 선택에 실제 변화 두 줄을 붙인다.** 보정 전 현재 장점을 위치로 지정하고, 후에는 같은 원본·사용 보기·썸네일을 비교해 `목표 변화: 위치와 관찰` / `기존 장점에 생긴 변화: 위치와 관찰`를 남긴다. 원본의 표면·경계, 사용 보기의 정보 연결, 썸네일의 큰 비중 중 해당 변화가 드러나는 근거를 쓴다. 목표 결함만 나아졌거나 설명 없이 기존 관계가 약해지면 최신본을 자동 채택하지 않는다. 기존 보정 한도 안에서 전체 요구에 맞는 결과를 고르고 미해결 조건은 보고한다. 새 호출·평가자·품질 게이트를 추가하는 절차가 아니다.
