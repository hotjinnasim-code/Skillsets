# R18 / U — 같은 생활수리 요청의 결합 설계 개발

R17과 같은 카피·조건의 16:9 생활수리 포스터 다섯 장을 U로 제작했다. 이미지와 실제 글자 덩어리를 함께 설계하고 각 문구의 역할·문단 줄 묶음을 정했으며, 새 코드 구성 스케치를 각 제작자의 참고 자료로 전달했다. 사용자 자산은 없고 스케치의 좌표는 보존 조건이 아니다. 최종 포스터는 모두 내장 이미지 도구의 반환 원본이다.

다섯 독립 제작자의 네이티브 호출은 12회 모두 반환됐다. 보정 호출은 7회이며 두 역할이 최초본을 선택했다. 그중 보정을 시도하지 않고 종료한 역할은 한 개다. 논리적 다섯 제작자와 실제 최대 세 동시 작업자를 구별한다.

최초와 선택의 세 평가자씩 모두 종료했다. 최초 평가의 세 실행 로그에는 실제 연결 재시도 오류 이벤트가 있어 기존 절차 기준이 NA를 보존했다. 완료된 원점수와 시각적 낮은 점수도 그대로 남긴다. 기술적 로그 오류를 디자인 실패로 해석하거나, 이를 이유로 평가자를 교체하지 않았다. 선택 단계의 절차·입력 결속·해당 원본 확인 감사는 통과했고 유효 원점수는 105개다.

선택 M1·M2·M5는 세 평가자 각각 일곱 항목 모두 4 이상과 필수 조건을 충족했다. M3는 editorial의 위계·정서가 3이며 다른 두 평가자의 4로 상쇄하지 않았다. M4는 모두 위계·공간이 3이고 정보 연결 조건의 실패도 남았다. 선택 다양성은 세 평가자 모두 4, AI 슬롭 항목은 15개의 원평가 모두 4였지만 이는 제작 주체 판별이나 전체 세트 통과를 뜻하지 않는다.

최초의 다양성 원점수는 세 평가자 모두 4였다. 본문은 대체로 이어 읽히지만 M3·M4의 위계는 모두 3이며 M2도 강조 경쟁의 잔여 문제가 반복됐다. 제목·초대·슬로건·보조 언어의 역할을 실제 크기·굵기·대비 관계로 구현하고, 분산된 관련 정보의 다음 시작을 찾는 단서를 이미지 편집과 함께 정할 필요가 남았다. 기호 길이와 의미 있는 단어 간격의 평가자 간 차이·FAIL·NA는 합의로 바꾸지 않는다. M4의 한 접촉 결함을 모든 사람·손·그림 표현의 금지로 확대하지 않는다.

같은 이미지의 평가 뒤 보정이나 재선택은 하지 않았다. 다음 지침에 반영할 공통 설계 가설을 얻은 개발 기록이며 모든 최초 결과의 하이엔드 품질이 입증됐다는 뜻은 아니다. 원본 레퍼런스 수나 스케치의 실제 글꼴 렌더링은 최종 래스터의 폰트 파일 적용·Unicode·품질을 보장하지 않는다.
