# Independent R7 critic rubric

Judge the exact literal client request and requested styles. Open style is open: infer the achieved concept from the pixels, without an author's concept explanation. Expressive, unusual, decorative or clay3D work can earn any score when it resolves the requested task. Do not impose a fixed house style, a hostile 3D ban, muted emotion or a genre substitution.

All three profiles independently score all seven dimensions. Editorial emphasizes message, content-grounded relationships, hierarchy and faithful copy. Craft emphasizes precise typography, spacing, material and image construction. Portfolio emphasizes specificity, cohesive finish, emotional intent as actually communicated and whether the work survives close inspection. These are emphases, not different scales, veto rules or permissions to omit dimensions.

The integer scale is: 1 unusable; 2 major unresolved problems; 3 functional but clearly unfinished or generic; 4 resolved, strong professional execution; 5 exceptional specific refinement. Use the full scale on observed evidence. Do not prefill scores, seek a predetermined pass/fail distribution, average away a weak dimension, or infer quality from a requested style name. The seven dimensions are:

- `content_form`: whether the actual nonglyph concept and composition communicate the specific supplied content and task.
- `hierarchy`: whether the reading sequence, focal relationships and supporting elements resolve the requested use.
- `typography`: glyph fidelity, optical handling, readability, spacing and deliberate type treatment across native/use/thumbnail.
- `space`: intentional proportions, margins, alignment and occupied/empty-space relationships rather than leftover gaps.
- `image_material`: coherent construction, scene/action legibility, requested material/style fidelity and convincing local detail.
- `emotion_control`: controlled, specific emotional effect appropriate to the literal requested genre, without flattening expressive genres.
- `ai_slop`: freedom from observable arbitrary decoration, repeated generic motifs, contradictory construction or unresolved generated artifacts. Judge observed defects, not a medium stereotype.

Before the first score, actually view every supplied source asset, then every packet member in order at native, usage720 and thumbnail320. Full viewing is 3N poster views per critic; N is the user's actual count. Source assets also require actual viewing before any fidelity judgment. Read a supplied protected-layout measurement manifest when present. Truthfully attest to your method and order; do not invent serialized tool events, successful opens or a runtime session ID.

Follow the pinned review_rules.md normalization exactly. Keep raw first reads, glyph/word/punctuation comparison, optical spacing, layout breaks and ambiguity distinct. One genuine ambiguity permits one revisit of the same pinned view, with both readings retained. Unresolved ambiguity is NA. A spacing difference does not establish a missing Hangul character. URL entries remain separately declared and their slash spacing is protected.

R7 predeclares `requirements.ratio_rounding:"nearest-integer-single-edge"` for aspect-only briefs: a native ratio is correct if it is mathematically exact OR `abs(width-height*a/b)<=0.5` OR `abs(height-width*b/a)<=0.5`. Use each image's `ratio_requirement` when present, otherwise the common ratio. Report actual native dimensions and whether correctness uses integer rounding; do not describe a rounded ratio as mathematically exact or resize the native. Explicit requested pixel dimensions disable this exception. This policy changes no aesthetic score or other mandatory condition.

The mandatory style check includes every literal client style and condition, not a coordinator's or maker's intended concept. `checked_requirement` must exactly copy the image's pinned `style_requirement`. Optional per-condition details may appear outside `mandatory`, but the mandatory style status must roll up every applicable literal condition: any definite violation -> FAIL, any genuinely unassessable condition -> NA, otherwise PASS. Such optional details never replace the required mandatory check.

Type/whitespace-only output, 3D lettering alone, a tiny ornament or a texture/gradient backdrop does not satisfy the current substantive nonglyph requirement. Locate the actual substantive visual and explain its contribution to the specific content. Evaluate asset identity and protected layout against the supplied sources before marking fidelity PASS.

For N>=2, compare all requested members as a set and give one independent diversity integer 1–5, with concrete evidence for each member and relationships across the set. Palette/filter substitutions alone are insufficient. For N=1 use explicit `diversity:null` and `not_applicable_reason:"single requested image"`. Preserve exact requested count and all low records. If actual viewing is impossible, truthfully set procedure attestations false and mandatory statuses NA; leave unjudgable score values null with reasons rather than fabricate integers. The resulting procedural NA is intentional.
