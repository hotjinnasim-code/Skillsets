# 다섯 제작자 역할로 만드는 독립된 포스터

신규 제작에서는 중앙 조정자가 전체 방향을 함께 설계하고 다섯 제작자 에이전트가 각각 한 장을 맡는다. 사용자 지정 수량이면 역할 수를 맞춘다. 가용 동시 실행 한도 안에서 실행하고 대기 중인 역할까지 끝낸다. 한 장의 후속 수정과 일반 제작에 외부 평가자를 자동으로 추가하지 않는다.

## 중앙에서 먼저 설계

원문·전체 카피·조건과 사용자 자료를 확정한다. 실제 스튜디오 작품과 필요한 Canva 템플릿의 전체 시각 체계를 조사하고 각 방향에 필요한 원리를 배분한다. 하나의 유명 스타일을 모든 역할에 공유하지 않는다. [아트디렉션](art-direction.md)의 표면을 가린 비교와 실제 내용 비교를 통과한 방향을 배정한다.

각 방향에는 현재 내용의 핵심, 전체 표현 체계, 장면·행동·시점·크롭, 실제 카피 그룹과 상대적 비중, 레이아웃과 글자 역할, 색·재질·정서, 가까운 다른 방향과 구별할 구조를 짧게 적는다. 공통 대제목·중앙 오브젝트·하단 정보 틀을 배정하지 않는다. 제작자는 실제 판독과 구현에 맞춰 같은 방향의 세부를 조정할 수 있으며 큰 관계를 바꾸면 이유를 알린다.

각 제작자에게 원문 전체, 확정된 전체 카피와 조건·비율, 자신이 맡은 한 방향, 관련 스킬 지침, 필요한 실제 사용자 자산과 역할, 조사에서 얻은 구체적인 원리를 전달한다. "배정된 방향 한 장만 제작하며 전체 수량은 중앙이 관리한다"고 명시한다. 제작자는 다른 제작자를 재귀적으로 추가하지 않는다.

다섯 제작자가 동시에 지원되면 모두 독립 실행한다. 한도가 더 낮으면 완료된 자리에 나머지 역할을 배정한다. 별도 채팅·작업이나 다른 실행 수단으로 한도를 우회하지 않는다. 논리적 다섯 역할과 실제 최대 동시 실행 수를 구별한다. 협업 도구가 없으면 같은 전체 설계로 직접 제작하고 실행하지 않은 에이전트를 주장하지 않는다.

## 제작자 한 명의 범위

배정된 전체 시각 관계와 다른 방향과의 구분을 유지하면서 실제 카피와 이미지를 하나의 포스터로 구체화한다. 다른 제작자의 생성 이미지·프롬프트를 읽거나 신규 참조로 쓰지 않는다. 필요한 공통 사용자 자료는 빠짐없이 받고 수정·구도·스타일·실제 대상 재현의 역할을 구별한다.

전체 요청은 제작자가 이해하고 검수할 맥락이다. 이미지 도구에는 인쇄 카피 한 벌과 필요한 조건, 선택한 구체적인 이미지·글자·공간 관계, 출력 조건만 명확히 담는다. 원문·카피·조건을 여러 형식으로 반복하거나 평가표·계획 JSON을 붙이지 않는다. 중요한 대상·행동·참조 조건을 잃으면 안 된다. 수정에는 바꿀 부분과 유지할 관계를 전달하고 매번 원문 전체로 결과를 검수한다.

내장 이미지 도구로 단일 평면 포스터 한 장을 실제 생성한다. 독립 출력 경로를 쓰고 원본을 보존한다. 축소·사용 크기·원본에서 전체 문구·조건·한글·구성·재질·AI 슬롭을 확인한다. 재생성을 포함한 자동 보정은 이미지당 최대 두 번이다. 직접 본 전후 결과에서 가장 적합한 최종본을 선택한다.

중앙에 원본·선택 최종본의 실제 경로, 반환 픽셀 크기, 모든 호출·보정 횟수, 문구·조건 확인과 잔여 문제를 돌려준다. 자신의 의도나 자기 점수로 실제 이미지 검수를 대신하지 않는다.

## 전체 다섯 장 확인

중앙은 모든 결과를 직접 보고 카피·조건을 대조한다. 나란히 놓인 실제 이미지에서 레이아웃·글자 역할·장면·공간까지 서로 다른지 확인한다. 가장 약한 시안도 같은 기준으로 본다. 겹치거나 미완성인 방향은 남은 보정 한도 안에서 해당 제작자에게 위치·원인·바꿀 관계·유지할 장점을 지정한다. 같은 이미지를 두 작업자가 동시에 수정하지 않는다. 중앙의 추가 호출도 같은 이미지의 이력에 합산한다.

각 역할의 성공·실패와 최종 파일 대응을 확인한 뒤 요청 수량을 모두 전달한다. 실패한 역할은 남은 범위에서 이어 수행하고, 한도·도구 문제나 미해결 결함은 숨기지 않는다. 일부 우수 결과 때문에 나머지를 생략하거나 미선택 보정본을 다른 스타일로 세지 않는다.
