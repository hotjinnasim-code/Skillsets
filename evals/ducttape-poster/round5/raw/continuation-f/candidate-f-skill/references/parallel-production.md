# 제작자 에이전트의 병렬 제작

협업 도구가 있는 신규 제작에서 읽는다. 기본은 중앙 조정자와 **서로 다른 방향을 맡은 제작자 다섯 명**이다. 사용자가 총수량을 지정하면 제작자 역할 수도 그 수량으로 맞춘다. 한 장의 후속 수정은 기존 이미지 한 장만 담당한다. 평가 전용 외부 리뷰를 일반 제작의 필수 단계로 추가하지 않는다.

## 중앙 조정자

원문에서 표시 카피와 필수 조건을 확정하고 전체 방향을 함께 설계한다. 아트디렉션의 방향 비교를 거친 뒤 각 제작자에게 **핵심 발상, 그것이 글자·이미지·정보의 관계에 미치는 결과, 가까운 다른 방향과 구분할 원리**를 짧게 준다. 원문에 없는 고정 구획·장면 비중·읽는 순서를 공통 템플릿으로 추가하지 않는다. 구체적인 시점·비례·정렬·카피 배치는 제작자가 배정된 관계와 원문 안에서 결정한다. 구도 유지 요청이나 중요한 대상 구조는 공통 필수 조건으로 전달한다.

각 제작자에게 원문 요청, 확정된 전체 카피, 공통 필수 조건·비율, 자신이 맡은 방향과 최종 한 장의 범위, 관련 스킬 지침, 실제 참조 이미지와 그 역할을 전달한다. 한 제작자가 전체 다섯 장을 다시 만들지 않게 **"당신은 배정된 방향 한 장만 제작하며 전체 수량은 중앙에서 관리한다"**고 명시한다. 제작자 모드에서는 다른 제작자를 재귀적으로 추가하지 않는다.

현재 제공되는 협업 도구의 실제 스키마와 동시 실행 한도를 따른다. 다섯 작업자를 동시에 지원하면 모두 독립적으로 실행한다. 가능한 작업자가 적으면 그 수만큼 먼저 실행하고 완료된 자리에 남은 제작자를 배정한다. 기다리는 역할도 포함해 총 다섯 역할과 최종 다섯 장은 유지한다. 슬롯을 억지로 늘리거나 새 채팅·작업을 만드는 것으로 한도를 우회하지 않는다. 사용자가 순차 제작을 명시하면 그 요청을 따른다.

## 각 제작자

배정된 핵심 관계와 다른 방향과의 구분을 유지하며 구체적인 구성과 제작 명세를 정한다. 중앙의 계획이 실제 카피 판독이나 대상 식별을 약하게 만들면 같은 방향 안에서 관계를 다시 설계하고 변경 이유를 중앙에 알린다. 다른 제작자의 생성 이미지·프롬프트를 읽거나 신규 생성의 참조로 쓰지 않는다. 공통 사용자 자료는 빠짐없이 받되 수정 대상, 구도·스타일 참고, 실제 대상 재현의 역할을 구분한다.

내장 이미지 도구로 단일 평면 포스터를 실제 생성한다. 독립된 출력 경로를 써서 다른 제작자의 파일을 덮어쓰지 않는다. 원본을 보존하고 축소·사용 크기·원본에서 카피·조건·한글·타이포그래피·구조·재질·AI 슬롭을 확인한다. 필요한 보정은 자신이 맡은 이미지에만 적용하며 재생성을 포함해 이미지당 최대 두 번이다.

중앙에 실제 원본과 선택 최종본의 경로, 픽셀 크기, 보정 횟수, 문구·조건 확인, 남은 문제를 돌려준다. 제작자의 자기 점수나 의도를 실제 결과 검수의 대체물로 삼지 않는다.

## 전체 결과 확인과 전달

중앙은 모든 결과를 직접 보고 카피·조건을 대조하며, 가장 약한 시안과 전체 다양성도 확인한다. 두 방향이 실질적으로 겹치거나 미완성인 결과가 있으면 남은 보정 한도 안에서 해당 제작자에게 위치·원인·바꿀 관계와 유지할 장점을 지정한다. 같은 이미지의 보정을 두 작업자가 동시에 수행하지 않는다. 중앙과 제작자의 추가 호출을 같은 이미지의 보정 이력으로 합산한다.

모든 역할의 성공·실패와 파일 대응을 확인한 뒤 방향별 최종 한 장을 전달한다. 완료된 한 장이 좋다는 이유로 나머지를 생략하지 않는다. 실패한 역할은 원인을 해결하고 남은 범위에서 이어 수행한다. 지원 한도나 도구 실패로 병렬 실행 또는 생성이 불가능하면 실제 상태와 남은 결과를 알리고 존재하지 않는 결과·에이전트 실행을 완료로 세지 않는다.
