# W 초안: 실제 카피와 이미지 관계를 최초 생성 전에 함께 설계

닫힌 R19의 최초·선택 집계와 원관찰을 읽고 작성한 지침 초안이다. 이미지 자체를 새로 열거나 재평가하지 않았다. 최초는 0 PASS / 5 FAIL, 선택은 1 PASS / 4 FAIL이며 두 단계 모두 전체 세트 FAIL이었다. 선택 단계의 다양성 원점수는 세 평가자 모두 4지만, 읽히는 카피가 있어도 내용 적합성·정서 제어·이미지 마감의 낮은 점수가 남았다. 이 원점수와 기록은 변경하지 않았다.

W는 현재 V의 12개 파일을 그대로 복사한 뒤 다섯 문서만 수정했다. 설명 문단과 실용 안내가 함께 들어가 조판과 이미지 면적을 조정해야 하는 요청에는 적합한 실제 글꼴·기존 렌더러가 있을 때 첫 네이티브 호출 전에 빠른 코드 구성 스케치를 작성하고 본 뒤 구성·글자 형태 참고로 사용하도록 했다. 실제 확정 카피와 문장 면적을 조판하고, 현재 내용에서 선택한 관계·상태·경험을 시점·대상 크기·크롭·연결·빛과 이미지 영역의 큰 형태로 같이 설계한다. 큰 글자만 보여 주거나 같은 이미지 둘레의 빈 정보 면에서 진입 문구·재료만 바꾸는 계획을 전체 구분의 근거로 삼지 않는다.

이 지침은 특정 식물 이미지의 보정 방법이 아니다. 고정 소재·시점·폰트·좌표·카피 그룹 수·다섯 스타일 메뉴를 추가하지 않았다. 무문자·제목만·간단한 카피에는 스케치를 의무로 늘리지 않는다. 현재 글꼴·렌더러가 없거나 문자를 지원하지 않으면 설치·API·승인 요청 없이 같은 실제 카피와 이미지 관계를 긍정적인 네이티브 제작 명세로 구체화한다. 사용자 지정 표현·배치·구도 보존을 우선하고 필요한 사용자 참조는 매 호출에 모두 포함한다. 이를 위해 계획 가이드의 도구 전달은 생략할 수 있다.

최종 포스터는 내장 image_gen으로 생성한다. 스케치는 새 계획 도형과 실제 글자이며 최종 오버레이·기존 래스터 편집·반환 포스터 재조판을 추가하지 않았다. 실제 스케치에 사용한 폰트 파일이 네이티브 최종 래스터에 적용됐다고 주장하지 않는다. 스케치의 좌표·크기·줄 수는 새 사용자 보존 조건이나 계획 일치만을 위한 보정 사유가 아니다. 사용자 이미지의 실제 열람·전달, 독립된 제작자 역할, 가용 동시 실행 한도, 이미지별 최대 두 번 보정과 원기록 보존은 유지했다.

변경은 `SKILL.md`, `references/production-brief.md`, `references/parallel-production.md`, `references/layout-guide.md`, `references/layout-guide-contract.md`다. 다른 일곱 파일은 V와 바이트가 같다. 렌더러 코드·평가 루프·평가표·원점수·테스트는 변경하지 않았다. 스킬 형식 검증은 통과했고 상대 파일 링크는 확인했다. 문서 초안 검증은 포스터 품질을 입증하지 않는다.

W의 실제 사용 결과는 아직 없다. 레이아웃 스케치가 첫 생성의 카피 면적과 이미지 관계를 더 구체적으로 전달할 수 있다는 설계 가설이며, 네이티브 모델이 선택한 글자 형태·영역·마감을 그대로 구현하거나 모든 요청이 하이엔드가 되는 것을 보장하지 않는다. 복잡한 카피 여부는 현재 의미·매체·공간 요구로 판단하며 새 숫자 문턱을 만들지 않았다. 기존 렌더러의 지원 문자·폰트·플랫폼 한계도 그대로 남는다.

실제 파일·바이트·변경 전후 해시는 `base-v-files.json`과 `changed-files.json`, 검증 및 읽은 근거는 `status.json`, 검토용 차이는 `draft.diff`에 기록한다. 라이브 V·동결 스냅샷·닫힌 평가 기록은 수정하지 않았고 스테이징·커밋·메인 변경을 하지 않았다.
