# 실제 산출물로 평가하는 루프

스킬 개선·비교·다중 에이전트 평가를 요청받았을 때만 읽는다. 일반 제작의 사용자 흐름을 늘리지 않는다.

## 비교 설계

같은 원문 요청·필수 카피·참조 자료·수량·비율·보정 한도를 기존 버전과 후보 버전에 적용한다. 버전별 스킬 사본과 내부 프롬프트, 실제 출력, 보정 이력을 평가용 작업 폴더에 저장한다. 산출물은 스킬 폴더에 섞지 않는다. 사용자 요청에 이미 평가가 포함되면 그 범위에서 진행하며 새 비용·외부 변경의 권한을 자동 확장하지 않는다.

별도 제작자에게 해당 버전의 스킬, 원문 요청과 원자료만 준다. 예상 정답·의심하는 오류·개선자의 결론을 주입하지 않는다. 도구 호출에 성공한 실제 이미지와 계획만 수행한 사례를 구별한다.

평가자는 이미지의 버전·프롬프트·스타일 설명을 숨긴 식별자로 같은 원문과 전체 결과를 받는다. 축소·사용 크기·원본을 직접 본다. 참조 충실도 평가는 필요한 원본 자료도 제공한다. 가능한 경우 디자인 평가와 카피·조건 평가를 독립적으로 수행한 뒤 차이와 불확실성을 함께 기록한다.

## 필수 통과 조건

카피의 누락·변형·발명, 읽을 수 없는 필수 정보, 사용자 조건 위반, 수량·독립 이미지 형식 오류, 확보하지 않은 실제 로고·화면의 정확한 재현 주장은 미적 장점과 별개로 기록한다. 판독이 애매한 한글·기호는 원본을 다시 확인하고 불확실성을 남긴다.

## 시각 평가의 기준점

각 항목은 실제 보이는 근거를 하나 이상 적는다. 2와 4는 아래 기준 사이이며, 총점을 합산해 결함을 덮지 않는다.

| 항목 | 1: 미해결 | 3: 기능하는 결과 | 5: 매우 잘 해결된 결과 |
| --- | --- | --- | --- |
| 내용과 형태 | 다른 주제에도 그대로 쓸 상투적 구성 | 주제를 반영하지만 일부 선택이 임의적 | 구체적인 발상이 주요 선택을 연결하며 억지 해석이 없음 |
| 정보 계층 | 시선 분산·순서 혼란 | 중심과 읽는 순서가 보임 | 축소의 첫 시선부터 사용 크기의 참여 안내까지 자연스럽게 연결 |
| 타이포그래피 | 글자가 덧붙여진 느낌·불균일한 간격 | 판독과 그룹화가 합리적 | 획·줄 묶음·크기·간격·배치가 이미지와 하나의 구성으로 작동 |
| 공간 | 임의 마진·접촉·죽은 공간 | 전체 균형과 정렬이 일관됨 | 크롭·무게·여백·경계의 큰 관계와 작은 관계가 의도적 |
| 이미지와 재질 | 원근·빛·경계·질감의 혼란 | 표현 체계가 대체로 일관됨 | 원본에서도 재질·형태·마감이 발상에 맞게 정교하거나 의도적으로 거침 |
| 정서와 제어 | 효과·장식의 축적에 의존 | 요청에 맞는 정서와 요소 | 절제든 과잉이든 표현이 정확하고 각 요소가 역할을 가짐 |
| AI 슬롭 방지 | 상투적 패키지·글자·재질의 합성 흔적이 두드러짐 | 기술적으로 일관되지만 범용적인 습관이 남음 | 내용에 특화된 편집·글자·공간·재질이 설득력 있고 눈에 띄는 합성 결함이 없음 |

전체 결과의 다양성은 별도로 판단한다. 1은 색·필터만 다른 반복, 3은 구분되지만 구조적 습관이 남음, 5는 공통 조건 안에서 각 방향의 발상·글자 역할·공간·이미지 표현이 설득력 있게 나뉨이다. 최고 시안뿐 아니라 최저 시안과 전체 분포를 본다.

AI 슬롭 점수는 제작 주체 판별이 아니다. [아트디렉션과 마감의 검수 기준](art-direction.md)을 실제 위치와 근거로 적용하며, 특정 스타일이라는 이유로 감점하지 않는다. 이 항목이 3 이하이거나 평가자에게 구체적인 합성 흔적이 보이면 하이엔드 후보로 단정하지 않고 보정하거나 잔여 문제로 기록한다. 평가 기준이 실행 중 추가되면 어느 버전에 반영됐고 어느 출력에 사후 적용했는지 기록한다.

## 수정과 종료

실제 관찰한 실패를 가장 작은 유효한 지침 변경으로 고친다. 같은 요청을 다시 실행하고, 다른 내용이나 제약의 사례에서도 확인한다. 포스터의 한두 결함 때문에 스타일·색상·소재를 전면 금지하지 않는다. 국소 이미지 보정과 스킬 지침 개선은 기록에서 구분한다.

평가 라운드와 도구 호출 수를 기록하고 실행 전에 유한한 범위를 정한다. 통상 두 번의 수정 라운드 안에서 비교 신호를 확인하고, 추가 실행이 필요하면 원인과 목적이 있어야 한다. 일반 제작의 이미지당 보정 한도는 그대로 지킨다. 한 번 좋은 결과가 나왔다고 종료 기준을 높여 무한히 생성하지 않는다.

필수 조건을 통과하고, 내용·글자·공간·마감에 실제 4–5 수준의 근거가 있는지 확인하되 이를 보편적 품질 인증으로 부르지 않는다. 평가자 사이에 승자·동률·불확실을 허용한다. 보고서에는 실행한 사례, 실제 이미지 수와 보정 수, 버전·파일, 남은 오류·판독 불확실성과 검증하지 않은 범위를 남긴다. 소수 사례는 개선 신호를 보여줄 뿐 안정적인 성공률을 증명하지 않는다.
